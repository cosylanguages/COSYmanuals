Advanced Passive & Causative Constructions

Complex passives (have/get something done, passives with modal perfects, double passives).

Core Rule: Use Have / Get + Object + Past Participle for causative arrangements, or Modal Perfect Passives (must have been + V3) for past logical necessity.

Causative / Passive TypeStructureExample Sentence
Causative HaveHave + Object + Past ParticipleThe firm had its accounts audited by an external agency.
Modal Perfect PassiveModal + have been + V3The document must have been altered prior to submission.
Double PassivePassive Verb + Passive InfinitiveThe decree was ordered to be published.

🗣️ Pronunciation Note

Ensure primary stress falls on the main participle (AU-di-ted, AL-tered).

Examples
  • We plan to have the security infrastructure overhauled next month.
  • The funds are believed to have been misallocated.
