# Legacy Generators Archive

These files are preserved for archived reference only.

- They were originally written for the COSYlanguages directory tree.
- They read input data from `COSYlanguages/vocabulary`, `COSYlanguages/curriculum`, and `COSYlanguages/reference-grammar`, and write outputs into `manuals/` (file paths have not been adapted).
- For active migration work in this repository, use `scripts/cosy_manuals_migrate.py`.
