# Template Differences

The following template files exist in both COSYlanguages and COSYmanuals but differ. COSYmanuals versions were preserved:

- `templates/communication/index-template.html`: COSYmanuals uses shared CSS links (`../../shared/styles/tokens.css`, etc.) whereas COSYlanguages used legacy CSS paths (`../../css/tokens.css`, etc.).
- `templates/communication/unit-template.html`: COSYmanuals uses shared CSS links (`../../shared/styles/tokens.css`, etc.) whereas COSYlanguages used legacy CSS paths (`../../../css/tokens.css`, etc.).
- `templates/grammar/lesson-template.html`: COSYmanuals uses shared CSS links (`../../shared/styles/tokens.css`, etc.) whereas COSYlanguages used legacy CSS paths (`../../../css/tokens.css`, etc.).
- `templates/grammar/roadmap-template.html`: COSYmanuals uses shared CSS links (`../../shared/styles/tokens.css`, etc.) whereas COSYlanguages used legacy CSS paths (`../../css/tokens.css`, etc.).
