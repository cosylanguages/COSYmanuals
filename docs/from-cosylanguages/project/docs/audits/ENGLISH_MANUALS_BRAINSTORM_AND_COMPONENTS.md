# COSYlanguages English Manuals — Visual Component Taxonomy & Pedagogical Blueprint

**Scope:** All English-language educational manuals across COSYlanguages — Grammar (A0–A1, A2, B1, B2), Vocabulary (A0–A1, A2, B1, B2), and Communication (A0–A1, A2, B1, B2).

---

## 1. Executive Summary & Pedagogical Philosophy

Visual patterns provide cognitive anchors that make abstract linguistic relationships immediately intuitive. Rather than memorizing isolated items or prose explanations, learners process structured relationships through four core visual shapes:

1. 📈 **Horizontal Gradient Scale (5 Stops)**: Represents linear continuums (intensity, frequency, degree, probability, formality).
2. 🌳 **Branching Decision Tree**: Represents discrete decision paths (grammatical choices, classification rules, contextual paths).
3. 🔄 **Circular Cycle**: Represents repeating or cyclical processes (routines, seasons, active listening loops, product development cycles).
4. 🧱 **Vertical Stack / Building Blocks**: Represents structural hierarchy or top-to-bottom spatial relationships (sentence assembly, body/clothing layers, building layouts, register ladders).

### 🎯 CEFR Level Strictness & Strategic Cross-Level Bridge Elements
- Each level manual strictly adheres to its target CEFR scope (A0–A1 elementary foundations, A2 pre-intermediate expansion, B1 intermediate nuance, B2 upper-intermediate mastery).
- **Cross-level bridge elements**: On select topics where contrasts clarify understanding (e.g., contrasting A1 *can* with B1 *be able to*, or A1 *I think* with B2 *It is widely posited that*), advanced forms are included in a distinct callout box marked with a bridge icon (🌉 *Bridge to higher level*) without overwhelming the core CEFR target.
