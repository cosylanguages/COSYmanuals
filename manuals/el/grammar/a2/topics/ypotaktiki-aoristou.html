Η Υποτακτική του Αορίστου

Θέλω να πάω, πρέπει να δω.

🎯 Επικοινωνιακός στόχος: Χρησιμοποιώ την υποτακτική αορίστου μετά από «να».
  • Θέλω να πάω στο γιατρό.
  • Πρέπει να δεις αυτό το έγγραφο.
  • Ελπίζω να τελειώσουμε νωρίς.
  • Προσπαθώ να μάθω ελληνικά.

ΝΑ + ΑΟΡΙΣΤΟΣ ΧΩΡΙΣ ΑΥΞΗΣΗ · να πάω, να δω, να κάνω

Παραδείγματα σε χρήση
  • Θέλω να πάω στο γιατρό. Η υποτακτική αορίστου δηλώνει μια στιγμιαία πράξη. — Να πάω, όχι «να πηγαίνω» για μία φορά.
  • Ελπίζω να τελειώσουμε νωρίς. Ο τύπος είναι ίδιος για όλα τα πρόσωπα. — Να τελειώσουμε.
  • Προσπαθώ να μάθω ελληνικά. Μετά από προσπαθώ ακολουθεί να. — Να μάθω.

👀 Τι παρατηρείτε;

Η υποτακτική αορίστου σχηματίζεται με το μόριο να και τον αόριστο χωρίς αύξηση: να πάω, να δεις, να κάνει, να πούμε, να δείτε, να φύγουν. Χρησιμοποιείται μετά από ρήματα όπως θέλω, μπορώ, πρέπει, ελπίζω, προσπαθώ, ξέρω, αρχίζω, σταματώ, και δηλώνει μια πράξη στιγμιαία ή ολοκληρωμένη στο μέλλον. Όταν η πράξη διαρκεί ή επαναλαμβάνεται, χρησιμοποιείται η υποτακτική ενεστώτα: θέλω να πηγαίνω κάθε μέρα.

★ Γιατί έχει σημασία

Είναι η δομή που εμφανίζεται σε κάθε δεύτερη πρόταση των ελληνικών: χωρίς υποτακτική δεν μπορείς να εκφράσεις επιθυμία, ανάγκη ή σκοπό.

💭 Σκεφτείτε σαν φυσικός ομιλητής

Στην καθομιλουμένη η υποτακτική αορίστου κυριαρχεί· η υποτακτική ενεστώτα χρησιμοποιείται συνειδητά για διάρκεια.

🗣️ Σημείωση προφοράς

Ο τόνος μένει στον τύπο χωρίς αύξηση: να ΠΑω, να ΔΩ.

Περισσότερα παραδείγματα
  • Επιθυμία: Θέλω να σου πω κάτι.
  • Ανάγκη: Πρέπει να φύγουμε τώρα.
  • Σκοπός: Ήρθα να σε βοηθήσω.
