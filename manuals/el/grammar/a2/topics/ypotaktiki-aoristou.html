Υποτακτική Αορίστου

Να / Για να / Όταν + θέμα Αορίστου για συγκεκριμένες επιθυμίες

🎯 Επικοινωνιακός στόχος: Έκφραση συγκεκριμένων αιτημάτων και σκοπών

Η Υποτακτική Αορίστου χρησιμοποιείται με τα μόρια να, για να, όταν, αν όταν αναφερόμαστε σε μια ενέργεια που θέλουμε να γίνει μία φορά (συγκεκριμένα).

ΜόριοΘέμα ΑορίστουΠαράδειγμα
νααγοράσ-ωΘέλω να αγοράσω ένα ψωμί.
για ναδ-ωΉρθα για να δω τον φίλο μου.
ότανφτάσ-ωΠάρσε με όταν φτάσεις.

👀 Προσοχή

Συγκρίνετε: Θέλω να πίνω νερό (γενικά/συνέχεια) vs Θέλω να πιω νερό (τώρα/μία φορά - Υποτακτική Αορίστου).

💡 Μνημονικός κανόνας

Υποτακτική Αορίστου = Να + Θέμα Αορίστου (Specific action)!

⚠️ Συνηθισμένα λάθη
✗ Θέλω να αγοράζω έναν καφέ. (αν θέλεις έναν καφέ τώρα)
πατήστε για τη σωστή μορφή
