Η Υποτακτική στην Ευχή

Να είσαι καλά, να περάσεις καλά.

🎯 Επικοινωνιακός στόχος: Εκφράζω ευχές και ευγενικές παρακλήσεις.
  • Να είσαι καλά!
  • Να περάσεις καλά!
  • Μακάρι να πάνε όλα καλά.
  • Να προσέχεις στο δρόμο.

ΝΑ + ΡΗΜΑ ΓΙΑ ΕΥΧΗ · ΜΑΚΑΡΙ + ΝΑ · να είσαι καλά

Παραδείγματα σε χρήση
  • Να είσαι καλά! Η ευχή σχηματίζεται με να και υποτακτική. — Να είσαι καλά, όχι «είσαι καλά».
  • Μακάρι να πάνε όλα καλά. Το μακάρι ενισχύει την ευχή. — Μακάρι να.
  • Να προσέχεις στο δρόμο. Η συμβουλή με να είναι ευγενική. — Να προσέχεις.

👀 Τι παρατηρείτε;

Η ευχή στα ελληνικά εκφράζεται με το μόριο να και την υποτακτική: να είσαι καλά, να περάσεις καλά, να πάνε όλα καλά, να προσέχεις. Το μακάρι προσθέτει ελπίδα: μακάρι να βρέξει. Η δομή χρησιμοποιείται και ως ευγενική εντολή ή συμβουλή, πιο μαλακή από την προστακτική: να πάρεις το φάρμακο, να μη αργήσεις. Στις ευχές για το παρελθόν χρησιμοποιείται να με παρατατικό: να ήσουν εδώ!

★ Γιατί έχει σημασία

Η ευχή είναι από τις πιο συχνές κοινωνικές πράξεις: χωρίς αυτήν δεν μπορείς να ευχηθείς γενέθλια, ταξίδι ή επιτυχία με φυσικό τρόπο.

💭 Σκεφτείτε σαν φυσικός ομιλητής

Στην καθομιλουμένη κυριαρχούν οι στερεότυπες ευχές: να είσαι καλά, καλή τύχη, να περάσεις καλά. Είναι οι πρώτες που μαθαίνει κανείς.
