Ο Σύντομος Μέλλοντας

Θα δώσω, θα βρω, θα πω.

🎯 Επικοινωνιακός στόχος: Αναγνωρίζω τους σύντομους τύπους του μέλλοντα.
  • Θα δώσω την απάντηση αύριο.
  • Θα βρω μια λύση.
  • Θα πω την αλήθεια.
  • Θα βγεις έξω απόψε;

ΘΑ + ΣΥΝΤΟΜΟΣ ΤΥΠΟΣ (δώσω, βρω, πω) · ΕΠΙΣΗΜΟ ΚΑΙ ΓΡΑΠΤΟ ΥΦΟΣ

Παραδείγματα σε χρήση
  • Θα δώσω την απάντηση αύριο. Το δίνω δίνει μέλλοντα θα δώσω. — Θα δώσω, όχι «θα δίνω» για μία πράξη.
  • Θα βρω μια λύση. Το βρίσκω δίνει θα βρω. — Θα βρω.
  • Θα πω την αλήθεια. Το λέω δίνει θα πω. — Θα πω.

👀 Τι παρατηρείτε;

Ορισμένα ρήματα έχουν σύντομους τύπους μέλλοντα, που μοιάζουν με τον αόριστο: δίνω δίνει θα δώσω, βρίσκω δίνει θα βρω, λέω δίνει θα πω, βγαίνω δίνει θα βγω, βλέπω δίνει θα δω, πίνω δίνει θα πιω. Οι τύποι αυτοί χρησιμοποιούνται σε όλα τα επίπεδα ύφους, αλλά εμφανίζονται συχνότερα σε επίσημο λόγο, σε ανακοινώσεις και σε γραπτά κείμενα. Στην υποτακτική εμφανίζονται ως να δώσω, να βρω, να πω.

Κανόνας: Μάθε τα ζευγάρια μαζί — δίνω/θα δώσω, βρίσκω/θα βρω — γιατί το λάθος «θα δίνω» για μία πράξη ακούγεται αμέσως.

★ Γιατί έχει σημασία

Οι σύντομοι τύποι εμφανίζονται σε ανακοινώσεις, σε επίσημες επιστολές και σε ειδήσεις: χωρίς αυτούς δεν καταλαβαίνεις ένα επίσημο κείμενο.

💭 Σκεφτείτε σαν φυσικός ομιλητής

Στην καθομιλουμένη ακούγονται το ίδιο συχνά: θα σου πω, θα βρω τρόπο. Δεν είναι λόγιοι τύποι.

🗣️ Σημείωση προφοράς

Ο τόνος στον σύντομο τύπο: θα ΔΩσω, θα ΒΡΩ.

Περισσότερα παραδείγματα
  • Ανακοίνωση: Η εταιρεία θα δώσει απάντηση μέχρι τη Δευτέρα.
  • Υπόσχεση: Θα σου πω αύριο.
  • Σχέδιο: Θα βρω έναν τρόπο.
