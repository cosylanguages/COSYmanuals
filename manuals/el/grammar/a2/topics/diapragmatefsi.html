Παραδείγματα σε χρήση
  • Θα μπορούσαμε να βρεθούμε στη μέση. Το θα μπορούσαμε προτείνει λύση χωρίς πίεση. — Θα μπορούσαμε.
  • Τι θα λέγατε για αυτή την τιμή; Η ερώτηση προσκαλεί σε συμφωνία. — Τι θα λέγατε για.
  • Αντί για δύο, θα προτιμούσα τρεις. Το αντί για εισάγει εναλλακτική. — Αντί για δύο.

👀 Τι παρατηρείτε;

Η διαπραγμάτευση γίνεται με ευγενικές δομές: θα μπορούσαμε να, τι θα λέγατε για, θα προτιμούσα, θα ήθελα, μήπως θα ήταν δυνατόν. Για να προτείνεις εναλλακτική χρησιμοποιείς αντί για ή θα προτιμούσα. Για να κλείσεις συμφωνία λες συμφωνούμε, έχει καλώς, κλείνουμε σε αυτό, ενώ για να αρνηθείς ευγενικά: λυπάμαι, δεν μπορώ να δεχτώ αυτόν τον όρο. Οι λέξεις κλειδιά είναι προσφορά, αντιπροσφορά, όρος, συμβιβασμός, συμφωνία.

★ Γιατί έχει σημασία

Η διαπραγμάτευση εμφανίζεται σε κάθε αγορά, ενοίκιο ή σύμβαση: η ευγενική δομή αφήνει χώρο και στις δύο πλευρές να συμφωνήσουν χωρίς να χάσουν το πρόσωπό τους.

💭 Σκεφτείτε σαν φυσικός ομιλητής

Στην καθομιλουμένη η διαπραγμάτευση είναι πιο άμεση: κάνε μου καλύτερη τιμή. Σε επίσημη συζήτηση προτιμώνται οι δομές με θα.
