Σχέδια και Υποσχέσεις

Θα πάω, σκοπεύω να πάω, υπόσχομαι.

🎯 Επικοινωνιακός στόχος: Μιλάω για σχέδια και αναλαμβάνω δεσμεύσεις.
  • Τον Ιούνιο θα πάω στην Κρήτη.
  • Σκοπεύω να ξεκινήσω γυμναστήριο.
  • Υπόσχομαι να σου τηλεφωνήσω.
  • Ελπίζω να τα καταφέρω.

ΘΑ + ΡΗΜΑ · ΣΚΟΠΕΥΩ / ΥΠΟΣΧΟΜΑΙ + ΝΑ · θα πάω, σκοπεύω να πάω

Παραδείγματα σε χρήση
  • Τον Ιούνιο θα πάω στην Κρήτη. Το θα δηλώνει σχέδιο. — Θα πάω, όχι «θα πήγαινα» για σχέδιο.
  • Σκοπεύω να ξεκινήσω γυμναστήριο. Το σκοπεύω θέλει να και υποτακτική. — Να ξεκινήσω.
  • Υπόσχομαι να σου τηλεφωνήσω. Η υπόσχεση θέλει να και υποτακτική. — Να τηλεφωνήσω.

👀 Τι παρατηρείτε;

Τα σχέδια εκφράζονται με το θα και τον στιγμιαίο μέλλοντα: θα πάω, θα ξεκινήσω, θα τελειώσω. Όταν θέλουμε να δηλώσουμε πρόθεση, χρησιμοποιούμε σκοπεύω να, σχεδιάζω να, έχω σκοπό να, πιστεύω να, ελπίζω να ακολουθούμενα από υποτακτική. Οι υποσχέσεις θέλουν υπόσχομαι να, δεσμεύομαι να ή απλώς το θα: θα σου τηλεφωνήσω. Με χρονικό προσδιορισμό το σχέδιο γίνεται πιο συγκεκριμένο: τον Ιούνιο, την επόμενη εβδομάδα, του χρόνου.

★ Γιατί έχει σημασία

Σχέδια και υποσχέσεις γεμίζουν τις συζητήσεις για δουλειά, ταξίδια και σπουδές: η διαφορά ανάμεσα σε «θα πάω» και «ελπίζω να πάω» αλλάζει την εντύπωση που δίνεις.
