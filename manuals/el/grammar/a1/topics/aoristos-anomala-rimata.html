Παραδείγματα σε χρήση
  • Χθες πήγα στο γιατρό. Το πηγαίνω δίνει πήγα. — Πήγα.
  • Είδα μια ταινία. Το βλέπω δίνει είδα. — Είδα.
  • Ήρθα αργά. Το έρχομαι δίνει ήρθα. — Ήρθα.

👀 Τι παρατηρείτε;

Πολλά συχνά ρήματα έχουν ανώμαλο αόριστο που δεν βγαίνει με κανόνα: πηγαίνω → πήγα, βλέπω → είδα, έρχομαι → ήρθα, κάνω → έκανα, παίρνω → πήρα, μαθαίνω → έμαθα, λέω → είπα, τρώω → έφαγα, πίνω → ήπια, δίνω → έδωσα, βγαίνω → βγήκα, μπαίνω → μπήκα, βρίσκω → βρήκα, ακούω → άκουσα, ξέρω → ήξερα. Οι καταλήξεις ακολουθούν το γνωστό σχήμα -α, -ες, -ε, -αμε, -ατε, -αν: πήγα, πήγες, πήγε, πήγαμε, πήγατε, πήγαν. Αυτοί οι τύποι χρειάζονται σε κάθε αφήγηση.

★ Γιατί έχει σημασία

Χωρίς αυτούς δεν μπορείς να πεις τι έγινε χθες: τα πιο συχνά ρήματα της καθημερινής ζωής είναι ακριβώς τα ανώμαλα.
