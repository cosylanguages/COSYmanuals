Question Tags

Add a short question to check or invite agreement.

🎯 What you can communicate after this page: You can build question tags that match the auxiliary, the polarity and the subject.
Examples in context
  • The file arrived, didn't it? Positive statement, negative tag. — Did carries the tense.
  • You haven't signed, have you? Negative statement, positive tag. — Have repeats the auxiliary.
  • Nobody called, did they? Negative meaning, positive tag, they for nobody. — Nobody takes they.

👀 What do you observe?

A question tag repeats the auxiliary of the statement with the opposite polarity: the file arrived, didn't it? A positive statement takes a negative tag, a negative statement a positive one. If the statement has no auxiliary, the tag uses do, does or did. The tag takes the subject pronoun, never a noun, and nobody, nothing and never count as negative, so the tag is positive.

Formula / rule: Copy the auxiliary, flip the polarity, and use a pronoun. If there is no auxiliary, the tag brings do, does or did. Then check the negative words, because nobody, never and hardly make the statement negative and the tag positive.

★ Why it matters

Tags carry the social move rather than the information: a falling tag invites agreement (it's cold, isn't it?), a rising tag asks a real question. In British English they are constant and in American English less so, and using the wrong polarity turns a friendly check into a challenge.

💭 Think like a native speaker

Native speakers use tags to open conversation (nice day, isn't it?) and to close an argument (I told you, didn't I?). In Indian and Singapore English, isn't it? works as a general tag, which is non-standard in British usage.

🗣️ Pronunciation note

A falling tag on a long vowel invites agreement; a rising tag asks. In speech the tag is unstressed when the speaker expects agreement: the file arrived, DIDn't it.

Additional example bank
  • Check: You're joining us, aren't you?
  • Invite agreement: The numbers are clear, aren't they?
  • Imperative: Pass the file, will you?
⚠️ Common mistakes to avoid

❌ Wrong: The file arrived, isn't it? (tag auxiliary taken from the wrong verb)

✅ Right: The file arrived, didn't it?

❌ Wrong: Nobody called, didn't they? (double negative: nobody plus a negative tag)

✅ Right: Nobody called, did they?
