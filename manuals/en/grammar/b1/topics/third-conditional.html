Level B2 Grammar

Third Conditional

Talk about a past that did not happen.

🎯 What you can communicate after this page: You can use if + past perfect with would have for unreal past situations.
Examples in context
  • If we had checked the file, we would have found the error. Unreal past. — Had checked, would have found.
  • She would have called if she had known. If-clause second. — Same pair, reversed order.
  • Had I seen it, I would have objected. Inverted, formal. — Had replaces if.

👀 What do you observe?

The third conditional describes an unreal past: something did not happen, and we imagine the consequence. It takes if plus the past perfect in the condition and would have plus the past participle in the result. Would never appears in the if-clause, and the inverted form Had I seen replaces if I had seen in formal writing.

Element / structure Role in English Application example
if + past perfect the unreal condition if we had checked the file
would have + participle the unreal result we would have found the error
if-clause second result first she would have called if she had known
inverted form Had + subject, formal had I seen it, I would have objected
negative wouldn't have + participle we wouldn't have lost the client
never would in the if-clause the commonest error if I had known, not if I would have known

Formula / rule: Decide that the situation is past and unreal, then put the past perfect in the condition and would have plus the participle in the result. If the register is formal, invert had and drop if.

★ Why it matters

The third conditional is the grammar of accountability and hindsight: if the file had been checked, the error would have been found is how a review states causation without stating blame. It is also the structure of every post-mortem, which is why it appears in every report of a failure.

💭 Think like a native speaker

Native speakers use it constantly in speech, usually contracted (we'd have found it), and many replace would have with would of in writing by mistake. The inverted form is reserved for formal speech and writing.

🗣️ Pronunciation note

The contraction carries the pattern: we'd have /wiːd əv/, often reduced to woulda in fast speech. The participle is stressed: we would have FOUND it.

Additional example bank
  • Unreal past: If the alarm had worked, the fire would have been contained.
  • Result first: They would have signed if the terms had been clearer.
  • Inverted: Had the audit been earlier, the loss would have been smaller.
⚠️ Common mistakes to avoid

❌ Wrong: If I would have known, I would have called (would in the if-clause)

✅ Right: If I had known, I would have called

❌ Wrong: If we had checked, we would found the error (missing have)

✅ Right: If we had checked, we would have found the error
