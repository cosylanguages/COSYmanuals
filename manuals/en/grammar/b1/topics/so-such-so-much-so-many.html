Level B2 Grammar

So, Such, So Much, So Many

Intensify an adjective, a noun or a quantity.

🎯 What you can communicate after this page: You can use so, such, so much and so many in the right pattern.
Examples in context
  • The report was so late. So before an adjective alone. — So + adjective.
  • It was such a long meeting. Such with a noun phrase. — Such + a + adjective + noun.
  • There were so many errors. So many with countable plurals. — So many + plural noun.

👀 What do you observe?

So intensifies an adjective or adverb alone: so late, so quickly. Such intensifies a noun phrase: such a long meeting, such errors. With quantities, so much goes with uncountable nouns and so many with countable plurals. The so ... that and such ... that patterns introduce a consequence. So is never used before a noun, and such never before an adjective alone.

Element / structure Role in English Application example
so + adjective intensifies an adjective the report was so late
such + a + adjective + noun intensifies a noun phrase such a long meeting
so much + uncountable quantity, uncountable so much noise
so many + plural quantity, countable so many errors
so / such ... that consequence so late that we missed the deadline
such + plural or uncountable no article such errors, such noise

Formula / rule: Look at what follows. An adjective or adverb on its own takes so. A noun phrase takes such, with a or an if the noun is singular countable. A quantity takes so much or so many according to countability. Then add that plus the consequence if the sentence needs one.

★ Why it matters

These four are the most reliable intensifier errors at B1, because the wrong one is still understandable and therefore never corrected by the listener. In writing they also do argumentative work: so many errors that we restarted states the consequence and the judgement in one clause.

💭 Think like a native speaker

Native speakers use so in speech for emphasis without a that-clause (it was so late), and such alone as a reaction (such a mess!). Both are informal and frequent.

🗣️ Pronunciation note

So and such are stressed when they carry the intensity: it was SO late; SUCH a long meeting.

Additional example bank
  • Adjective: The queue was so slow that we left.
  • Noun phrase: It was such a short notice period that nobody applied.
  • Quantity: So much paperwork, so little time.
⚠️ Common mistakes to avoid

❌ Wrong: It was so long meeting that we left (so before a noun phrase)

✅ Right: It was such a long meeting that we left

❌ Wrong: There were so much errors (much with a countable plural)

✅ Right: There were so many errors
