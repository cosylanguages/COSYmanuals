Level B2 Grammar

Passive with Modals

Keep the modal and put the verb in the passive.

🎯 What you can communicate after this page: You can use must be, can be, should have been and might be in the passive.
Examples in context
  • The form must be signed today. Present obligation, passive. — Must be + participle.
  • The file should have been checked. Past criticism, passive. — Should have been + participle.
  • The room can be booked online. Possibility, passive. — Can be + participle.

👀 What do you observe?

In a modal passive the modal stays first, be follows it, and the main verb is a past participle: must be signed, can be booked, might be shared. For a past judgement the pattern is modal plus have been plus the participle: should have been checked, must have been sent. The agent, if named, comes in a by-phrase.

Element / structure Role in English Application example
modal + be + participle present or future passive the form must be signed
modal + have been + participle past passive judgement the file should have been checked
can be possibility, passive the room can be booked online
must be obligation, passive the form must be signed today
might / may be possibility, passive the data might be shared later
by-phrase only when the agent matters must be signed by both parties

Formula / rule: Choose the modal for the meaning, then insert be before the participle. Shift to have been for a past reference. Keep the participle unchanged and add by only if the reader needs to know who acts.

★ Why it matters

The modal passive is the register of rules and procedures: forms must be signed, rooms can be booked, figures should have been checked. It states an obligation or a possibility without naming the person, which is exactly what a policy needs and exactly what an accountability report must avoid.

💭 Think like a native speaker

Native speakers use the present modal passive constantly in instructions and hedge with it: this should be checked before publication. The past form, should have been, is the standard written form of criticism.

🗣️ Pronunciation note

Be is weak after the modal, and the participle carries the stress: the form must be SIGNED today; the file should have been CHECKED.

Additional example bank
  • Rule: All returns must be authorised by a manager.
  • Possibility: The site can be reached by train.
  • Criticism: The figures should have been verified.
⚠️ Common mistakes to avoid

❌ Wrong: The form must signed today (missing be)

✅ Right: The form must be signed today

❌ Wrong: The file should have checked (missing been)

✅ Right: The file should have been checked
