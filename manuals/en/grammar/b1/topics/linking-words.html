Linking Words

Connect ideas and show the relation between them.

🎯 What you can communicate after this page: You can choose connectors for addition, contrast, cause, result and example.
Examples in context
  • The bid was late and incomplete. Addition, same direction. — And joins equal ideas.
  • It was expensive, but it worked. Contrast. — But takes a comma before it.
  • Costs rose, so we cut the scope. Result. — So introduces the consequence.

👀 What do you observe?

Linking words fall into five relations: addition (and, moreover, in addition), contrast (but, however, although, whereas), cause (because, since, as), result (so, therefore, consequently), and example (for example, for instance, such as). Some join clauses inside a sentence, others open a new sentence with a comma. However and therefore are adverbs, not conjunctions, so they need a full stop or a semicolon before them.

contrast but, although, whereas, however expensive, but it worked
cause because, since, as failed because the file was missing
result so, therefore, consequently costs rose, so we cut the scope
example for example, such as software such as the audit tool
punctuation however and therefore are adverbs it failed. However, we retried.

Formula / rule: Name the relation first, then pick the connector: same direction, opposite, reason, consequence, illustration. Then check the punctuation, because the adverb connectors need a boundary before them while the conjunctions do not.

★ Why it matters

Connectors are the argument. Two facts joined by because make a claim about causation, the same two joined by and make no claim at all. A reader follows the reasoning through these words, which is why a report with no connectors reads as a list and a report with the wrong ones reads as a non sequitur.

💭 Think like a native speaker

Native speakers overuse so and but in speech and switch to therefore and however in writing; using however in conversation sounds formal. In academic writing, moreover and consequently are frequent and rarely wrong.

🗣️ Pronunciation note

The connector usually carries a light stress at the start of its clause: it was expensive, BUT it worked; costs rose, SO we cut the scope.

Additional example bank
  • Contrast in writing: The timetable was met. However, the budget was not.
  • Cause: Since the file is missing, the audit cannot close.
  • Example: We use tools such as the audit log.
⚠️ Common mistakes to avoid

❌ Wrong: It was expensive, however it worked (comma splice with an adverb connector)

✅ Right: It was expensive. However, it worked.

❌ Wrong: The audit failed, because of the file was missing (preposition used as a conjunction)

✅ Right: The audit failed because the file was missing
