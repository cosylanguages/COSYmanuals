Level A2 Grammar

Second Conditional

Talk about imaginary situations.

🎯 What you can communicate after this page: You can describe an unreal or unlikely present with if plus the past simple and would in the other half.
Examples in context
  • If I had more time, I would learn the guitar. Unreal present. — Would in the result.
  • If she were here, she would know what to do. Were for all persons. — Formal and standard.
  • If I didn't work Saturdays, I would see my friends. A negative condition. — Past simple after if.

👀 What do you observe?

The second conditional describes something imagined, unlikely or contrary to the present. The if half takes the past simple, and were is the usual form of be for every person, especially in writing. The result half takes would plus the base verb, and could or might replace would when the result is a possibility rather than a certainty.

Element / structure Role in English Application example
if + past simple imagined condition if I had more time
would + base verb imagined result I would learn the guitar
were be for all persons if she were here
could, might uncertain results I could help
unless if not unless I had time, I would not try
comma only with the if half first If I had time, I would learn.

Formula / rule: Use the second conditional for the unreal or the unlikely. Past simple after if, would in the result, and were rather than was after if.

★ Why it matters

The past tense here is not about the past: it is the distance marker that tells the listener this is imagination, not fact. That is why I would help you and I will help you promise different things, and the second conditional is the standard way to be polite about a refusal.

💭 Think like a native speaker

Native speakers use if I was in conversation and if I were in writing and formal speech. Would of in the if half, as in if I would have time, is a common native slip and still non-standard.

🗣️ Pronunciation note

The result half carries the stress: I would LEARN the GUITAR. Would is unstressed and usually contracts to I'd.

Additional example bank
  • Imagined: If we lived by the sea, we would swim every day.
  • Advice: If I were you, I would apply now.
  • Polite refusal: I would help if I had the time.
⚠️ Common mistakes to avoid

❌ Wrong: If I would have more time, I would learn the guitar (would in the if half)

✅ Right: If I had more time, I would learn the guitar

❌ Wrong: If I was you, I would apply (informal was)

✅ Right: If I were you, I would apply
