Level A2 Grammar

Zero Conditional

State what always happens.

🎯 What you can communicate after this page: You can state a general truth or a rule with if plus the present simple in both halves.
Examples in context
  • If you heat ice, it melts. A law of nature. — Both verbs are present simple.
  • If I miss the bus, I am late for work. A personal routine. — The result follows every time.
  • If the button is red, the machine is off. A rule of the machine. — If means whenever here.

👀 What do you observe?

Zero conditional describes something that is always true: a fact, a law, a habit or an instruction. Both halves take the present simple, and if can be replaced by when with no change of meaning. The order of the two halves is free, but only the half with if takes a comma when it comes first.

Element / structure Role in English Application example
If + present simple the condition if you heat ice
present simple the automatic result it melts
when same meaning as if here when you heat ice
comma only when the if half comes first If it rains, we stay in.
imperatives instructions take the same pattern if it rains, take the car
never will will does not belong here if you heat ice, it will melt ✗ (for a law)

Formula / rule: Use the zero conditional when the result follows every time the condition is met. Present simple in both halves, if or when in the first, comma only when the condition comes first.

★ Why it matters

It is the pattern of facts and instructions, so it appears in science writing, manuals and safety notices far more than in conversation. Using will instead makes a general truth sound like a single prediction.

💭 Think like a native speaker

Native speakers use when more often than if for habits: when I get home, I check the post. The if version suggests a condition, the when version a routine.

🗣️ Pronunciation note

Keep the rhythm even across the two halves: IF you heat ICE, it MELTS. The stress falls on the content words, not on if.

Additional example bank
  • Fact: If you mix blue and yellow, you get green.
  • Habit: If she works late, she eats at the office.
  • Instruction: If the alarm sounds, leave the building.
⚠️ Common mistakes to avoid

❌ Wrong: If you will heat ice, it melts (will in the if half)

✅ Right: If you heat ice, it melts

❌ Wrong: If it rains, we will stay in (used for a general truth)

✅ Right: If it rains, we stay in
