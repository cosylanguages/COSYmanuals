Множественное число существительных

Именительный падеж множественного числа (-ы / -и, -а / -я)

📱 Словарная тема для практики: Предметы и вещи

🔗 Связь тем

Связано со страницей «Грамматический род» (стр. 11).

РодОкончание ед.ч.Окончание мн.ч.Пример
Мужской / Женскийтвёрдый согласный / -а-ыстол → столы́, газе́та → газе́ты
Мужской / Женскийг, к, х, ж, ч, ш, щ / -ь / -я-икни́га → кни́ги, вра́ч → врачи́
Средний-о → -а, -е → -я-а / -яокно́ → о́кна, мо́ре → моря́
Особые формыисключенияразныебра́т → бра́тья, дру́г → друзья́, челове́к → лю́ди

👁️ Обрати внимание

Запоминайте правило 7 букв: после г, к, х, ж, ч, ш, щ пишется только -и, никогда не -ы!

⚠️ Частые ошибки
❌книгы
нажмите, чтобы увидеть правильную форму
✅кни́ги (после «г» только «и»)
❌столи
нажмите, чтобы увидеть правильную форму
✅столы́ (твёрдый согласный)
Ещё примеры
  • два бра́та → бра́тья
  • хоро́шие друзья́
  • краси́вые города́
