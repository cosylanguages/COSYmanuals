Pronoms relatifs composés de déplacement

Décrire un parcours avec par lequel, vers lequel, dans lequel.

🎯 Objectif de communication : Vous savez employer les relatifs composés avec les prépositions de déplacement.
Exemples en contexte
  • Exemple 1 : Le couloir par lequel on accède au cloître est étroit. — Par lequel : passage.
  • Exemple 2 : La salle vers laquelle montent les visiteurs est fermée. — Vers laquelle : direction.
  • Exemple 3 : Le jardin dans lequel se trouve la statue est ouvert. — Dans lequel : lieu.

👀 Qu'observez-vous ?

Relatif composé = préposition + lequel (accordé). Déplacement : par lequel (passage), vers lequel (direction), dans lequel (lieu), jusqu'auquel (limite), à travers lequel (traversée).

Élément / Structure Rôle en français Exemple d'application
par lequel passage le couloir par lequel on accède
vers lequel direction la salle vers laquelle on monte
dans lequel intérieur le jardin dans lequel se trouve la statue
jusqu'auquel limite le palier jusqu'auquel on monte
à travers lequel traversée le vitrail à travers lequel passe la lumière
autour duquel contournement la place autour de laquelle on tourne

Formule / Règle : Préposition + lequel accordé avec l'antécédent. Les prépositions de déplacement (par, vers, dans, jusqu'à, à travers, autour de) précisent le type de mouvement.

★ Pourquoi c'est important

Ces relatifs évitent les phrases juxtaposées dans une description de parcours de visite : ils donnent au texte sa continuité.

💭 Pensez comme un francophone

À l'oral, on simplifie souvent : « le couloir qui mène au cloître ». La précision du relatif composé appartient à l'écrit.

🗣️ Note de prononciation

par lequel /paʁ lə.kɛl/, vers laquelle /vɛʁ la.kɛl/.

Banque d'exemples complémentaires
  • Passage : L'escalier par lequel on descend est étroit.
  • Direction : La terrasse vers laquelle on se dirige.
  • Traversée : La verrière à travers laquelle entre la lumière.
