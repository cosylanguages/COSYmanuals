Grammaire Française B1

Le futur dans le passé

Rapporter ce qui allait arriver.

🎯 Objectif de communication : Vous savez employer le futur dans le passé et être sur le point de au passé.
Exemples en contexte
  • Exemple 1 : Nous étions sur le point de partir quand il a appelé. — Imminence passée.
  • Exemple 2 : Il a dit qu'il viendrait le lendemain. — Futur dans le passé.
  • Exemple 3 : Le train allait partir quand nous sommes arrivés. — Action imminente.

👀 Qu'observez-vous ?

Futur dans le passé : conditionnel (il viendrait), aller à l'imparfait + infinitif (il allait partir), être sur le point de à l'imparfait, devoir à l'imparfait (il devait arriver).

Élément / Structure Rôle en français Exemple d'application
conditionnel futur dans le passé il a dit qu'il viendrait
aller à l'imparfait + infinitif imminence passée le train allait partir
être sur le point de (imparfait) imminence forte nous étions sur le point de partir
devoir à l'imparfait prévision passée il devait arriver à midi
le lendemain repère du discours rapporté il viendrait le lendemain
quand + passé composé interruption nous allions partir quand il a appelé

Formule / Règle : Quand on rapporte au passé ce qui était futur au moment des faits, le futur simple devient conditionnel : « il viendra » → « il a dit qu'il viendrait ». C'est la concordance des temps du discours rapporté.

★ Pourquoi c'est important

Aller à l'imparfait + infinitif décrit une action imminente vue du passé : « nous allions partir » signifie que le départ était sur le point de se produire.

💭 Pensez comme un francophone

Devoir à l'imparfait exprime une prévision : « il devait arriver à midi » — on attendait son arrivée à midi.

🗣️ Note de prononciation

il viendrait /il vjɛ̃.dʁɛ/, nous allions partir /nu.z‿a.ljɔ̃ paʁ.tiʁ/.

Banque d'exemples complémentaires
  • Discours rapporté : Elle a annoncé qu'elle partirait en avril.
  • Imminence : Nous allions fermer quand le client est entré.
  • Prévision : Le colis devait arriver lundi.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : il a dit qu'il viendra (après un verbe au passé)

✅ Correct : il a dit qu'il viendrait

❌ Erreur : nous sommes sur le point de partir quand il a appelé (récit au passé)

✅ Correct : nous étions sur le point de partir
