Grammaire Française B1

Les pronoms relatifs composés

Relier deux propositions avec une préposition précise.

🎯 Objectif de communication : Vous savez employer auquel, dans lequel et les autres relatifs composés.
Exemples en contexte
  • Exemple 1 : Le service auquel je m'adresse ne répond pas. — S'adresser à → auquel.
  • Exemple 2 : Le contrat dans lequel figure cette clause est clair. — Figurer dans → dans lequel.
  • Exemple 3 : Les conditions auxquelles je souscris sont écrites. — Souscrire à → auxquelles.

👀 Qu'observez-vous ?

Relatif composé : préposition + lequel accordé. À + lequel → auquel, auxquels, auxquelles ; de + lequel → duquel ; dans, sur, pour, avec, sans + lequel (accordé).

Élément / Structure Rôle en français Exemple d'application
auquel à + lequel le service auquel je m'adresse
auxquelles à + lesquelles les conditions auxquelles je souscris
duquel de + lequel le service duquel je dépends
dans lequel intérieur le contrat dans lequel figure la clause
sur lequel appui le formulaire sur lequel j'écris
pour lequel but le motif pour lequel je réclame

Formule / Règle : Préposition + lequel accordé avec l'antécédent. Les contractions avec à et de sont obligatoires : auquel, duquel, auxquels, auxquelles, desquels, desquelles.

★ Pourquoi c'est important

Ces relatifs donnent de la précision à un courrier juridique : ils désignent exactement le document ou le service concerné.

💭 Pensez comme un francophone

À l'oral, on préfère souvent « le service où je m'adresse » ou une phrase coupée : « je m'adresse à ce service. Il ne répond pas. »

🗣️ Note de prononciation

auquel /o.kɛl/, dans lequel /dɑ̃ lə.kɛl/.

Banque d'exemples complémentaires
  • À : Le service auquel je m'adresse est fermé.
  • Dans : Le contrat dans lequel figure la clause.
  • Pour : Le motif pour lequel je réclame.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le service à lequel je m'adresse

✅ Correct : le service auquel je m'adresse

❌ Erreur : les conditions auquel je souscris

✅ Correct : les conditions auxquelles je souscris
