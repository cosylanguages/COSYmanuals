Grammaire Française B1

Le passif formel pour décrire une propagation

Raconter comment une information circule sans nommer les responsables.

🎯 Objectif de communication : Vous savez décrire la diffusion d'une information au passif.
Exemples en contexte
  • Exemple 1 : La rumeur a été diffusée en quelques heures. — Agent non nommé : passif.
  • Exemple 2 : L'image a été modifiée avant publication. — Le fait est présenté sans accusateur.
  • Exemple 3 : Le message a été partagé des milliers de fois. — Propagation décrite objectivement.

👀 Qu'observez-vous ?

Le passif (être + participe passé) décrit un processus en mettant le fait au premier plan. Le complément d'agent (par) reste souvent absent quand il est inconnu, multiple ou sans intérêt. Le participe s'accorde avec le sujet.

Élément / Structure Rôle en français Exemple d'application
a été diffusée fait accompli la rumeur a été diffusée
est partagée usage ou état l'information est partagée en masse
a été modifiée transformation l'image a été modifiée
a été démentie correction la nouvelle a été démentie
sera vérifiée action à venir l'information sera vérifiée
par + agent agent connu le texte a été publié par un anonyme

Formule / Règle : Passif = être (au temps voulu) + participe passé accordé. L'agent se place après par (ou de avec certains verbes). Sans agent, la phrase reste neutre : c'est la tournure de l'information factuelle.

★ Pourquoi c'est important

Le passif permet de décrire un phénomène collectif sans désigner un coupable, ce qui convient à l'analyse des rumeurs.

💭 Pensez comme un francophone

À l'oral, on préfère souvent « on a diffusé » ; le passif appartient plutôt à l'écrit journalistique.

🗣️ Note de prononciation

a été diffusée /a e.te di.fy.ze/, avec liaison dans a‿été.

Banque d'exemples complémentaires
  • Fait : La rumeur a été diffusée en une nuit.
  • Correction : L'information a été démentie le lendemain.
  • Agent connu : Le texte a été publié par un compte anonyme.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : la rumeur a diffusé

✅ Correct : la rumeur a été diffusée : le sujet subit l'action

❌ Erreur : les images a été modifiées

✅ Correct : les images ont été modifiées : accord du verbe et du participe
