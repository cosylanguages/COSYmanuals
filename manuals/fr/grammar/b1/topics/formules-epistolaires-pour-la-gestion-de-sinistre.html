Les formules d'une déclaration de sinistre

Déclarer un dommage dans les formes.

🎯 Objectif de communication : Vous savez rédiger une déclaration de sinistre.
Exemples en contexte
  • Exemple 1 : Je vous informe d'un sinistre survenu le 12 mai dans mon logement. — Objet et date.
  • Exemple 2 : Les dégâts portent sur la cuisine et le couloir. — Description.
  • Exemple 3 : Je vous prie de bien vouloir mandater un expert. — Demande.

👀 Qu'observez-vous ?

Formule / Règle : Une déclaration de sinistre doit permettre à l'assureur de décider : date, nature, localisation, estimation, pièces jointes. L'absence d'un de ces éléments retarde l'instruction.

★ Pourquoi c'est important

Survenu le est la formule consacrée pour dater l'événement ; elle évite l'ambiguïté entre la date du constat et celle du sinistre.

💭 Pensez comme un francophone

Je vous prie de bien vouloir mandater est la demande formelle d'expertise ; elle appartient au registre épistolaire.

🗣️ Note de prononciation

survenu le /syʁ.və.ny lə/, les dommages /le dɔ.maʒ/.

Banque d'exemples complémentaires
  • Objet : Je vous informe d'un dégât des eaux survenu le 3 avril.
  • Description : Les dégâts portent sur le plafond du séjour.
  • Demande : Je vous prie de bien vouloir mandater un expert.
