Grammaire Française B1

Le futur proche pour les rendez-vous

Organiser ce qui va se faire bientôt.

🎯 Objectif de communication : Vous savez employer aller + infinitif pour un projet proche.
Exemples en contexte
  • Exemple 1 : Je vais appeler le client dans l'après-midi. — Action imminente.
  • Exemple 2 : Nous allons fixer la date lundi. — Décision proche.
  • Exemple 3 : Elle va envoyer le devis ce soir. — Intention.

👀 Qu'observez-vous ?

Futur proche : aller au présent + infinitif. Il marque une action imminente ou déjà décidée. Différence avec le futur simple : le proche est plus oral, plus immédiat, et souvent une intention.

Élément / Structure Rôle en français Exemple d'application
aller + infinitif action imminente je vais appeler le client
dans l'après-midi repère proche je vais appeler dans l'après-midi
ce soir / demain repère immédiat elle va envoyer le devis ce soir
nous allons fixer décision proche nous allons fixer la date lundi
être sur le point de imminence forte je suis sur le point de partir
je vais + infinitif intention je vais relancer le fournisseur

Formule / Règle : Le futur proche et le futur simple ne sont pas interchangeables dans un courriel professionnel : « je vais vous envoyer le devis » annonce une intention immédiate, « je vous enverrai le devis » prend un engagement. Le second est plus ferme.

★ Pourquoi c'est important

Pour un rendez-vous, le futur proche domine à l'oral : « je vais passer vous voir demain ». À l'écrit, on préfère souvent le futur simple ou le présent.

💭 Pensez comme un francophone

Être sur le point de marque une imminence plus forte : l'action va se produire dans l'instant.

🗣️ Note de prononciation

je vais appeler /ʒə vɛ.z‿a.ple/, sur le point de /syʁ lə pwɛ̃ də/.

Banque d'exemples complémentaires
  • Immédiat : Je vais relancer le service dans la matinée.
  • Décision : Nous allons bloquer deux créneaux pour l'essai.
  • Imminence : Le technicien est sur le point d'arriver.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : je vais vous envoyer le devis (engagement ferme écrit)

✅ Correct : je vous enverrai le devis

❌ Erreur : je vais appeler de le client

✅ Correct : je vais appeler le client
