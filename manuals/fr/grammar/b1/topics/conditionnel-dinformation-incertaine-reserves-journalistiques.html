Grammaire Française B1

Conditionnel d'information incertaine

Rapporter une information non confirmée sans l'affirmer.

🎯 Objectif de communication : Vous savez employer le conditionnel journalistique pour signaler une information non vérifiée.
Exemples en contexte
  • Exemple 1 : Selon nos informations, le projet serait reporté. — Information non confirmée.
  • Exemple 2 : Le ministre aurait démissionné hier soir. — Le conditionnel signale la rumeur.
  • Exemple 3 : Trois personnes seraient blessées. — Le journaliste ne prend pas position.

👀 Qu'observez-vous ?

Le conditionnel journalistique présente un fait comme non confirmé. Il s'accompagne de sources prudentes : selon, d'après, on affirme que, il semblerait que, il serait question de. Sans cette marque, le lecteur croit à une information vérifiée.

aurait fait non confirmé le ministre aurait démissionné

Formule / Règle : Conditionnel d'incertitude : serait, aurait, pourrait, aurait été. Sources prudentes : selon, d'après, il semblerait que + subjonctif, il serait question de + nom. Le conditionnel ne dit pas que c'est faux, mais que ce n'est pas confirmé.

★ Pourquoi c'est important

Cette nuance protège juridiquement le journaliste et informe le lecteur du degré de certitude : c'est une exigence déontologique.

💭 Pensez comme un francophone

À l'oral, le conditionnel d'incertitude s'entend peu ; on le remplace par « il paraît que ».

🗣️ Note de prononciation

il serait reporté /il sə.ʁɛ ʁə.pɔʁ.te/.

Banque d'exemples complémentaires
  • Rumeur : Selon nos informations, le directeur aurait démissionné.
  • Projet : Il serait question d'un report.
  • Bilan : Trois personnes seraient blessées.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le projet sera reporté, selon nos informations

✅ Correct : le projet serait reporté, selon nos informations

❌ Erreur : il semblerait qu'il a démissionné

✅ Correct : il semblerait qu'il ait démissionné
