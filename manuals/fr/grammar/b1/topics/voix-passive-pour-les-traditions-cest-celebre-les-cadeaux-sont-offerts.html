Grammaire Française B1

La voix passive des traditions

Décrire un usage collectif.

🎯 Objectif de communication : Vous savez décrire une tradition à la voix passive.
Exemples en contexte
  • Exemple 1 : Les cadeaux sont offerts le 25 décembre. — Usage daté.
  • Exemple 2 : C'est célébré dans toute la région. — Usage localisé.
  • Exemple 3 : La galette est partagée en famille, la fève désignant le roi. — Usage et coutume.

👀 Qu'observez-vous ?

Traditions : être + participe, c'est + participe, être célébré / offert / partagé / fêté, avoir lieu, se dérouler, il est de coutume de.

Élément / Structure Rôle en français Exemple d'application
être offert usage les cadeaux sont offerts le 25 décembre
c'est célébré usage collectif c'est célébré dans toute la région
être partagé coutume familiale la galette est partagée en famille
avoir lieu / se dérouler événement la fête a lieu au village
il est de coutume de usage établi il est de coutume d'apporter un dessert
être suivi de enchaînement rituel le repas est suivi d'une promenade

Formule / Règle : Le passif convient aux traditions parce qu'il efface les individus : ce qui compte est l'usage, non celui qui l'accomplit. « Les cadeaux sont offerts le 25 » décrit une coutume ; « on offre les cadeaux » décrit ce que font les gens.

★ Pourquoi c'est important

C'est célébré attire l'attention sur le caractère partagé de l'usage, souvent avec une localisation : dans toute la région, dans le village.

💭 Pensez comme un francophone

Il est de coutume de signale un usage sans obligation : la nuance est importante dans un texte qui décrit sans prescrire.

🗣️ Note de prononciation

il est de coutume /il ɛ də ku.tym/, c'est célébré /sɛ se.le.bʁe/.

Banque d'exemples complémentaires
  • Usage : Le pain est rompu avant le repas.
  • Localisation : Cette fête est célébrée depuis le XIXe siècle.
  • Coutume : Il est de coutume de laisser un présent à l'hôte.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : on offre les cadeaux le 25 décembre (description d'usage)

✅ Correct : les cadeaux sont offerts le 25 décembre

❌ Erreur : c'est célébré de dans toute la région

✅ Correct : c'est célébré dans toute la région
