Grammaire Française B1

Expressions de droit et de devoir

Distinguer ce qu'on peut exiger de ce qu'on doit faire.

🎯 Objectif de communication : Vous savez exprimer un droit et un devoir avec les tournures appropriées.
Exemples en contexte
  • Exemple 1 : Les citoyens ont le droit de demander un référendum. — Droit : avoir le droit de + infinitif.
  • Exemple 2 : Chacun a le devoir de s'informer. — Devoir moral : avoir le devoir de.
  • Exemple 3 : Les élus sont tenus de rendre des comptes. — Obligation juridique : être tenu de.

👀 Qu'observez-vous ?

Droit : avoir le droit de + infinitif, être en droit de, pouvoir exiger. Devoir : avoir le devoir de, être tenu de, devoir + infinitif, il est du devoir de + nom. L'obligation juridique emploie être tenu de.

Élément / Structure Rôle en français Exemple d'application

être en droit de permission fondée être en droit de demander

Formule / Règle : Le droit autorise (avoir le droit de, être en droit de) ; le devoir oblige (avoir le devoir de, être tenu de, devoir). La négation est fréquente : ne pas avoir le droit de, ne pas être tenu de.

★ Pourquoi c'est important

Cette distinction est la base du vocabulaire civique : confondre droit et devoir fausse tout le débat public.

💭 Pensez comme un francophone

À l'oral, « j'ai pas le droit » domine ; à l'écrit, gardez la forme complète ne pas avoir le droit de.

🗣️ Note de prononciation

être tenu de /ɛtʁ tə.ny də/, avoir le devoir de /a.vwaʁ lə də.vwaʁ də/.

Banque d'exemples complémentaires
  • Droit : Chacun a le droit de consulter le dossier.
  • Devoir : Les élus ont le devoir de rendre des comptes.
  • Obligation légale : L'employeur est tenu de déclarer l'accident.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : j'ai le devoir de voter, c'est un droit

✅ Correct : voter est à la fois un droit et un devoir : précisez la tournure

❌ Erreur : je suis tenu de pouvoir partir

✅ Correct : j'ai le droit de partir : être tenu de exprime une obligation
