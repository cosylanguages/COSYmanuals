Grammaire Française B1

Je voulais savoir si…

Poser une question avec distance.

🎯 Objectif de communication : Vous savez poser une question indirecte à l'imparfait.
Exemples en contexte
  • Exemple 1 : Je voulais savoir si le dossier était complet. — Question indirecte.
  • Exemple 2 : Je me demandais si vous aviez reçu ma demande. — Distance polie.
  • Exemple 3 : Pourriez-vous me confirmer si la date est maintenue ? — Confirmation demandée.

👀 Qu'observez-vous ?

Question indirecte : je voulais savoir si + indicatif (imparfait ou plus-que-parfait), je me demandais si, pourriez-vous me confirmer si. L'imparfait atténue, même quand le fait est actuel.

Élément / Structure Rôle en français Exemple d'application
je voulais savoir si question atténuée je voulais savoir si le dossier était complet
je me demandais si distance polie je me demandais si vous aviez reçu ma demande
pourriez-vous me confirmer si confirmation pourriez-vous me confirmer si la date est maintenue
j'aimerais savoir si demande j'aimerais savoir si le poste est pourvu
si + indicatif question totale si le dossier était complet
ce que / ce qui question partielle je voulais savoir ce qui manquait

Formule / Règle : Je voulais savoir si est la formule des demandes écrites : l'imparfait éloigne la question et la rend moins directe. Le fait rapporté peut être au présent ou au passé, selon le sens.

★ Pourquoi c'est important

L'imparfait de je voulais savoir ne signifie pas que la demande est ancienne : c'est un imparfait de politesse, comme dans je venais vous demander.

💭 Pensez comme un francophone

Pour une question partielle, si laisse place à ce qui, ce que, quand, comment : je voulais savoir quand la décision serait prise.

🗣️ Note de prononciation

je voulais savoir /ʒə vu.lɛ sa.vwaʁ/, je me demandais /ʒə mə də.mɑ̃.dɛ/.

Banque d'exemples complémentaires
  • Demande : Je voulais savoir si le délai était confirmé.
  • Relance : Je me demandais si ma demande vous était parvenue.
  • Partielle : Je voulais savoir quand la commission se réunit.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : je veux savoir si le dossier est complet (demande écrite polie)

✅ Correct : je voulais savoir si le dossier était complet

❌ Erreur : je voulais savoir de si

✅ Correct : je voulais savoir si
