Grammaire Française B1

La forme passive pour exprimer les consignes

Énoncer une règle municipale sans désigner l'agent.

🎯 Objectif de communication : Vous savez énoncer une consigne au passif.
Exemples en contexte
  • Exemple 1 : Les poubelles sont ramassées le mardi. — Consigne au passif présent.
  • Exemple 2 : Les encombrants doivent être sortis la veille. — Obligation au passif.
  • Exemple 3 : Le tri est contrôlé par les agents municipaux. — Agent exprimé quand il compte.

👀 Qu'observez-vous ?

Consigne au passif : être + participe (+ le + jour) ; devoir être + participe (obligation). L'agent n'est exprimé que s'il est identifiable et utile : par les agents municipaux.

Élément / Structure Rôle en français Exemple d'application
sont ramassées consigne hebdomadaire les poubelles sont ramassées le mardi
doivent être sortis obligation les encombrants doivent être sortis la veille
est contrôlé par agent identifiable le tri est contrôlé par les agents
sont collectés collecte les déchets verts sont collectés
doit être déposé obligation individuelle le bac doit être déposé devant l'immeuble
sont interdits interdiction les dépôts sauvages sont interdits

Formule / Règle : Consigne : passif présent (sont ramassées), obligation (doivent être + participe), interdiction (sont interdits). L'agent s'exprime avec par quand il est nommable.

★ Pourquoi c'est important

C'est le registre de l'affiche municipale : la règle est impersonnelle, donc applicable à tous.

💭 Pensez comme un francophone

Le pronominal peut remplacer le passif : « les poubelles se sortent la veille » : plus familier, mais fréquent à l'oral.

🗣️ Note de prononciation

sont ramassées /sɔ̃ ʁa.ma.se/, doivent être sortis /dwa.və.t‿ɛtʁ sɔʁ.ti/.

Banque d'exemples complémentaires
  • Collecte : Les bacs sont collectés le jeudi.
  • Obligation : Le bac doit être sorti la veille au soir.
  • Interdiction : Les dépôts sauvages sont interdits.
