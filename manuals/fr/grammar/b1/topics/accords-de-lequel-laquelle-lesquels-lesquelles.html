Grammaire Française B1

Accords de lequel, laquelle, lesquels, lesquelles

Faire accorder le pronom relatif composé avec son antécédent.

🎯 Objectif de communication : Vous savez accorder lequel et ses formes avec l'antécédent.
Exemples en contexte
  • Exemple 1 : Le document auquel je fais référence date de mars. — Le pronom s’accorde avec le nom repris : le document, masculin singulier.
  • Exemple 2 : La réunion à laquelle je participe est longue. — Antécédent féminin singulier : laquelle.
  • Exemple 3 : Les collègues avec lesquels je travaille sont patients. — Antécédent masculin pluriel : lesquels.

👀 Qu'observez-vous ?

Lequel s'accorde en genre et en nombre avec l'antécédent : lequel, laquelle, lesquels, lesquelles. Il s'emploie après une préposition (avec, sur, pour, dans) quand qui ne suffit pas.

Élément / Structure Rôle en français Exemple d'application
lequel masculin singulier le dossier sur lequel
laquelle féminin singulier la réunion à laquelle
lesquels masculin pluriel les collègues avec lesquels
lesquelles féminin pluriel les questions auxquelles

Formule / Règle : Lequel / laquelle / lesquels / lesquelles s'accordent avec l'antécédent et suivent une préposition. Avec à et de, les formes se contractent : auquel, duquel.

★ Pourquoi c'est important

L'accord est une faute très visible à l'écrit professionnel. Une erreur d'accord décrédibilise un courriel soigné.

💭 Pensez comme un francophone

À l'oral, on évite souvent le relatif composé au profit de « que » ou d'une reformulation : « la réunion que j'ai eue ».

🗣️ Note de prononciation

lequel /lə.kɛl/, laquelle /la.kɛl/, lesquelles /le.kɛl/.

Banque d'exemples complémentaires
  • Masculin singulier : Le rapport sur lequel je travaille.
  • Féminin pluriel : Les questions auxquelles je réponds.
  • Masculin pluriel : Les dossiers pour lesquels nous votons.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : la réunion auquel je participe

✅ Correct : la réunion à laquelle je participe

❌ Erreur : les documents laquelle j'ai besoin

✅ Correct : les documents dont j'ai besoin
