Grammaire Française B1

Les comparatifs d'efficience

Comparer la performance de deux solutions techniques.

🎯 Objectif de communication : Vous savez comparer deux solutions avec les comparatifs d'efficience.
Exemples en contexte
  • Exemple 1 : Cet algorithme est plus rapide que l'ancien. — Comparatif de rapidité.
  • Exemple 2 : La nouvelle version consomme deux fois moins d'énergie. — Comparatif de quantité.
  • Exemple 3 : Le système est aussi fiable qu'avant, mais moins coûteux. — Égalité et infériorité combinées.

👀 Qu'observez-vous ?

Comparatifs d'efficience : plus / moins / aussi + adjectif + que ; deux fois plus / moins + nom + que ; aussi efficace que, plus performant que, moins énergivore que. Le complément de mesure se place avant le comparatif.

plus rapide que vitesse plus rapide que l'ancien
moins coûteux que coût moins coûteux que la version précédente
aussi fiable que fiabilité aussi fiable qu'avant

moins énergivore que consommation moins énergivore que l'ancien système

Formule / Règle : Comparaison de performance : plus / moins / aussi + adjectif + que. Mesure : deux fois plus / moins de + nom. Le comparatif doit porter sur un critère mesurable, sinon il reste une opinion.

★ Pourquoi c'est important

Un argument technique sans critère est une affirmation : « plus rapide » n'a de sens que si l'on précise sur quelle tâche et dans quelles conditions.

💭 Pensez comme un francophone

Les fiches techniques emploient le comparatif avec la référence explicite : « 30 % plus rapide que la version 2 ».

🗣️ Note de prononciation

moins énergivore /mwɛ̃.z‿e.nɛʁ.ʒi.vɔʁ/, avec liaison.

Banque d'exemples complémentaires
  • Vitesse : Le modèle est plus rapide que le précédent.
  • Coût : La solution est moins coûteuse à l'usage.
  • Mesure : Le système consomme deux fois moins d'énergie.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : plus rapide de l'ancien

✅ Correct : plus rapide que l'ancien

❌ Erreur : deux fois moins d'énergie que de l'ancien

✅ Correct : deux fois moins d'énergie que l'ancien système
