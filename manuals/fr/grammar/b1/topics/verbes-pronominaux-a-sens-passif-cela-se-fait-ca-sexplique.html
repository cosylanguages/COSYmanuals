Grammaire Française B1

Verbes pronominaux à sens passif

Décrire un usage ou un processus sans nommer l'agent.

🎯 Objectif de communication : Vous savez employer cela se fait, ça s'explique et les verbes pronominaux passifs.
Exemples en contexte
  • Exemple 1 : Cela se fait en deux étapes. — Usage général, sans agent.
  • Exemple 2 : Ça s'explique par la distance. — Cause présentée sans responsable.
  • Exemple 3 : Le télétravail se développe dans toutes les équipes. — Processus en cours.

👀 Qu'observez-vous ?

Les verbes pronominaux à sens passif décrivent ce qui arrive à un sujet sans qu'un agent soit nommé : cela se fait, ça s'explique, le dossier se traite en ligne, les prix se négocient. Le sujet est patient, non acteur.

Élément / Structure Rôle en français Exemple d'application
cela se fait usage cela se fait en deux étapes
ça s'explique cause implicite ça s'explique par le contexte
se traiter processus administratif le dossier se traite en ligne
se négocier processus commercial les prix se négocient
se développer évolution le télétravail se développe
se pratiquer usage collectif le télétravail se pratique deux jours par semaine

Formule / Règle : Pronominal passif = se + verbe à la troisième personne, sans agent exprimé. On l'emploie pour les usages, les procédures et les évolutions. Pour nommer l'agent, on préfère le passif avec par : le dossier est traité par le service.

★ Pourquoi c'est important

C'est la tournure des procédures et des chartes : elle décrit une règle sans désigner un coupable, ce qui la rend acceptable dans un document collectif.

💭 Pensez comme un francophone

À l'oral, ces formes sont fréquentes : « ça se fait pas » signifie « ce n'est pas convenable ».

🗣️ Note de prononciation

cela se fait /sə.la sə fɛ/, ça s'explique /sa sɛks.plik/.

Banque d'exemples complémentaires
  • Usage : Cela se fait en deux temps.
  • Processus : Les demandes se déposent en ligne.
  • Évolution : Cette pratique se répand.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : cela est fait par on

✅ Correct : cela se fait

❌ Erreur : le dossier se traite par le service
