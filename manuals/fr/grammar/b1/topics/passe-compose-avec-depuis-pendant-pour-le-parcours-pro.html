Grammaire Française B1

Depuis, pendant, pour

Situer une durée dans un parcours professionnel.

🎯 Objectif de communication : Vous savez employer depuis, pendant et pour avec les temps corrects.
Exemples en contexte
  • Exemple 1 : Je travaille dans ce service depuis trois ans. — Depuis + présent.
  • Exemple 2 : J'ai travaillé deux ans à l'étranger. — Pendant + passé composé.
  • Exemple 3 : Je suis parti pour six mois. — Pour + durée prévue.

👀 Qu'observez-vous ?

Depuis + présent (action qui continue), pendant + passé composé ou imparfait (durée achevée), il y a + durée + passé composé, dans + durée + futur, pour + durée prévue.

Élément / Structure Rôle en français Exemple d'application
depuis + présent durée qui continue je travaille ici depuis trois ans
pendant + passé composé durée achevée j'ai travaillé deux ans à l'étranger
il y a + durée point de départ passé j'ai changé de poste il y a deux ans
dans + durée + futur échéance future je partirai dans trois mois
pour + durée prévue durée envisagée je suis parti pour six mois
depuis que + indicatif point de départ depuis que je coordonne l'équipe

Formule / Règle : Depuis exprime une durée qui se poursuit : il appelle le présent. Pendant exprime une durée bornée, achevée : il appelle le passé composé ou l'imparfait. C'est la distinction que les apprenants confondent le plus souvent.

★ Pourquoi c'est important

Depuis avec un verbe au passé composé est possible si l'action est négative ou répétée : « je n'ai pas travaillé depuis mars ». Avec une action positive en cours, le présent s'impose.

💭 Pensez comme un francophone

Il y a et dans sont symétriques : il y a regarde le passé, dans le futur.

🗣️ Note de prononciation

depuis /də.pɥi/, pendant /pɑ̃.dɑ̃/.

Banque d'exemples complémentaires
  • En cours : J'occupe ce poste depuis janvier.
  • Achevée : J'ai occupé ce poste pendant deux ans.
  • Future : Je prendrai mes fonctions dans un mois.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : je travaille ici pendant trois ans (en cours)

✅ Correct : je travaille ici depuis trois ans

❌ Erreur : j'ai travaillé deux ans depuis (durée achevée)

✅ Correct : j'ai travaillé deux ans pendant
