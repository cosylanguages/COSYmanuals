Grammaire Française B1

Contractions avec à (auquel) et de (duquel)

Former auquel, auxquels, duquel, desquels et les employer.

🎯 Objectif de communication : Vous savez contracter à + lequel et de + lequel.
Exemples en contexte
  • Exemple 1 : Le projet auquel je pense est ambitieux. — à + lequel = auquel.
  • Exemple 2 : La question à laquelle je réponds est simple. — à + laquelle reste invariable : à laquelle.
  • Exemple 3 : Le dossier duquel je parle est clos. — de + lequel = duquel.

👀 Qu'observez-vous ?

à + lequel → auquel ; à + lesquels → auxquels ; à + lesquelles → auxquelles. de + lequel → duquel ; de + lesquels → desquels ; de + lesquelles → desquelles. Les formes féminines singulières ne se contractent pas : à laquelle, de laquelle.

Seules les formes masculines et les pluriels se contractent avec à et de.
Élément / Structure Rôle en français Exemple d'application
à + lequel masculin singulier auquel
à + laquelle féminin singulier à laquelle
à + lesquels masculin pluriel auxquels
à + lesquelles féminin pluriel auxquelles
de + lequel masculin singulier duquel
de + laquelle féminin singulier de laquelle
de + lesquels masculin pluriel desquels
de + lesquelles féminin pluriel desquelles

Formule / Règle : Les contractions suivent la préposition et l'accord : auquel, auxquels, auxquelles ; duquel, desquels, desquelles. Au féminin singulier, aucune contraction.

★ Pourquoi c'est important

Ces formes évitent les phrases lourdes : « le projet auquel je pense » remplace « le projet à penser auquel ».

💭 Pensez comme un francophone

À l'oral, on préfère souvent une reformulation : « le projet dont je parle » plutôt que « duquel je parle ».

🗣️ Note de prononciation

auquel /o.kɛl/, duquel /dy.kɛl/, auxquels /o.kɛl/ (liaison avec la suite).

Banque d'exemples complémentaires
  • Avec à : La personne à laquelle je pense.
  • Avec de : Le collègue duquel je dépends.
  • Pluriel : Les dossiers auxquels nous travaillons.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le projet à lequel je pense

✅ Correct : le projet auquel je pense

❌ Erreur : la personne auquel je pense

✅ Correct : la personne à laquelle je pense
