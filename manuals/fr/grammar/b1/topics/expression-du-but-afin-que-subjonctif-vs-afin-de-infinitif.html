Grammaire Française B1

Afin que + subjonctif ou afin de + infinitif

Choisir la forme du but selon les sujets.

🎯 Objectif de communication : Vous savez employer afin que et afin de selon que les sujets sont identiques ou différents.
Exemples en contexte
  • Exemple 1 : Nous collectons des dons afin de financer l'atelier. — Même sujet : afin de + infinitif.
  • Exemple 2 : Afin que chacun participe, le local ouvre le samedi. — Sujets différents : afin que + subjonctif.
  • Exemple 3 : Nous ouvrons le soir afin que les salariés puissent venir. — Deux sujets, subjonctif obligatoire.

👀 Qu'observez-vous ?

Afin de + infinitif quand le sujet de la subordonnée est celui de la principale. Afin que + subjonctif quand les sujets diffèrent. Pour que suit la même règle.

afin de + infinitif même sujet afin de financer l'atelier

Formule / Règle : But : afin de / pour + infinitif (même sujet) ; afin que / pour que + subjonctif (sujets différents). Le subjonctif est obligatoire après afin que, même quand le fait est probable.

★ Pourquoi c'est important

C'est la règle qui distingue une phrase correcte d'une phrase bancale dans les courriels collectifs : « afin que chacun puisse » et non « afin de chacun puisse ».

💭 Pensez comme un francophone

À l'oral, pour que domine largement ; afin que appartient à un registre plus soutenu et à l'écrit.

🗣️ Note de prononciation

afin que /a.fɛ̃ kə/, afin de /a.fɛ̃ də/.

Banque d'exemples complémentaires
  • Même sujet : Nous ouvrons le samedi afin d'accueillir les familles.
  • Sujets différents : Nous ouvrons le samedi afin que les familles viennent.
  • But négatif : Nous fermons tôt de peur que le quartier soit désert.
