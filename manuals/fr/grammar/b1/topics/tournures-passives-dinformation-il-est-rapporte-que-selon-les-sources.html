Les tournures d'information

Rapporter une information non confirmée.

🎯 Objectif de communication : Vous savez rapporter une information sans en garantir la source.
Exemples en contexte
  • Exemple 1 : Il est rapporté que le texte serait modifié. — Information non confirmée.
  • Exemple 2 : Selon plusieurs sources, la décision serait imminente. — Source plurielle.
  • Exemple 3 : Le daily annonce un accord, information non confirmée à ce stade. — Prudence.

👀 Qu'observez-vous ?

Information non confirmée : il est rapporté que, selon + source, d'après + source, il semblerait que, serait + participe, information non confirmée, on parle de, il se murmure que.

Formule / Règle : Ces tournures protègent celui qui rapporte : elles attribuent l'information à une source et signalent qu'elle n'est pas vérifiée. Le conditionnel est la marque principale de cette distance.

★ Pourquoi c'est important

Selon plusieurs sources est plus prudent que selon une source : la pluralité suggère une vérification croisée. D'après nos informations engage la rédaction.

💭 Pensez comme un francophone

Information non confirmée est la formule explicite ; elle est préférable au conditionnel seul quand le risque de malentendu est élevé.

🗣️ Note de prononciation

il est rapporté /i.l‿ɛ ʁa.pɔʁ.te/, selon plusieurs sources /sə.lɔ̃ ply.zjœʁ suʁs/.

Banque d'exemples complémentaires
  • Rapport : Il est rapporté que deux ministres se sont entretenus.
  • Attribution : Selon deux sources proches du dossier, le vote serait reporté.
  • Prudence : Cette information n'a pas été confirmée par la direction.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : il est rapporté que le texte est modifié (non confirmé)

✅ Correct : il est rapporté que le texte serait modifié

❌ Erreur : selon les sources de que

✅ Correct : selon des sources proches du dossier
