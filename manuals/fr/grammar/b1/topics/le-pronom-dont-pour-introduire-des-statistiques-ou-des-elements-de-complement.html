Grammaire Française B1

Le pronom dont pour introduire une statistique

Chiffrer une réalité sans alourdir la phrase.

🎯 Objectif de communication : Vous savez employer dont pour introduire une donnée chiffrée.
Exemples en contexte
  • Exemple 1 : L'écart dont on parle atteint douze pour cent. — Dont reprend parler de.
  • Exemple 2 : La part dont bénéficient les femmes progresse. — Dont reprend bénéficier de.
  • Exemple 3 : Les secteurs dont le salaire moyen baisse sont nombreux. — Dont reprend le complément du nom.

👀 Qu'observez-vous ?

Dont remplace un complément introduit par de : parler de, bénéficier de, dépendre de, être composé de. Il sert aussi à introduire une statistique : la part dont bénéficient les salariés, le taux dont il est question.

Formule / Règle : Dont remplace de + nom, quel que soit le verbe. Il ne se combine pas avec une autre préposition : pour « parler de », on emploie dont seul ; pour « dépendre de », également dont.

★ Pourquoi c'est important

C'est l'outil des textes chiffrés : il permet d'enchaîner une statistique sans répéter le complément, ce qui rend la phrase lisible.

💭 Pensez comme un francophone

Beaucoup d'apprenants écrivent « dont… de » par hypercorrection : c'est la faute la plus fréquente avec ce pronom.

🗣️ Note de prononciation

dont /dɔ̃/, avec liaison devant voyelle : l'écart dont‿on parle.

Banque d'exemples complémentaires
  • Statistique : Le taux dont il est question atteint douze pour cent.
  • Complément du nom : La part dont le montant augmente.
  • Verbe en de : Le secteur dont dépend l'emploi.
⚠️ Erreurs fréquentes à éviter
