Grammaire Française B1

Qui, que, où, dont

Relier deux propositions sur un nom.

🎯 Objectif de communication : Vous savez employer les quatre relatifs de base.
Exemples en contexte
  • Exemple 1 : Le dossier qui est arrivé hier est incomplet. — Qui = sujet.
  • Exemple 2 : Le rapport que nous avons reçu est clair. — Que = objet.
  • Exemple 3 : La salle où se tient la réunion est au premier étage. — Où = lieu ou temps.

👀 Qu'observez-vous ?

Qui (sujet), que (objet), où (lieu, temps), dont (de + nom). Dont remplace de qui, duquel, de quoi : le sujet dont je parle, l'auteur dont le livre.

Élément / Structure Rôle en français Exemple d'application
qui sujet le dossier qui est arrivé
que objet le rapport que nous avons reçu
où lieu ou temps la salle où se tient la réunion
dont complément en de le sujet dont je parle
dont + nom possession l'auteur dont le livre a été primé
ce dont de + idée ce dont j'ai besoin

Formule / Règle : Qui et que sont les plus fréquents ; dont est celui que les apprenants évitent, alors qu'il est obligatoire après les verbes construits avec de : parler de, avoir besoin de, s'occuper de.

★ Pourquoi c'est important

Dont ne se cumule pas avec un autre complément en de : on ne dit pas « le sujet dont je parle de ». C'est la faute classique.

💭 Pensez comme un francophone

Où s'emploie pour le lieu et le temps, jamais pour la personne : « la personne où » est fautif.

🗣️ Note de prononciation

dont /dɔ̃/, où /u/.

Banque d'exemples complémentaires
  • Sujet : La personne qui coordonne le projet est absente.
  • Objet : La décision que nous attendons est reportée.
  • Dont : Le service dont je dépends est à Lyon.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le sujet dont je parle de

✅ Correct : le sujet dont je parle

❌ Erreur : la personne où je pense

✅ Correct : la personne à laquelle je pense
