Les subordonnées du droit de la concurrence

Qualifier un comportement par une subordonnée exacte.

🎯 Objectif de communication : Vous savez construire les subordonnées d'une analyse concurrentielle.
Exemples en contexte
  • Exemple 1 : Il y a abus de position dominante dès lors que l'entreprise exploite sa position pour empêcher le maintien d'une concurrence effective. — Définition par subordonnée.
  • Exemple 2 : L'échange d'informations est anticoncurrentiel pour autant qu'il porte sur des données stratégiques. — Condition de qualification.
  • Exemple 3 : La pratique est justifiée dans la mesure où elle produit un gain d'efficacité dont le consommateur bénéficie. — Exception d'efficacité.

👀 Qu'observez-vous ?

Concurrence : dès lors que + indicatif, pour autant que + subjonctif, dans la mesure où + indicatif, en ce qu'elle + verbe, à condition que + subjonctif, sous réserve que.

Formule / Règle : L'analyse concurrentielle procède par qualification : un comportement n'est anticoncurrentiel que si une condition est remplie, et cette condition s'énonce dans une subordonnée. La subordonnée n'est donc pas un ornement, mais le lieu de la qualification.

★ Pourquoi c'est important

Dès lors que introduit la définition, dans la mesure où l'exception d'efficacité, pour autant que la condition de qualification. Changer de subordonnée, c'est changer de test juridique.

💭 Pensez comme un francophone

En ce qu'elle est la subordonnée de motivation : elle explique en quoi consiste le grief. Son usage distingue l'analyse motivée du simple constat.

Banque d'exemples complémentaires
  • Définition : La pratique est restrictive dès lors qu'elle réduit l'accès au marché.
  • Condition : L'échange est problématique pour autant qu'il porte sur les prix futurs.
  • Exception : La restriction est admise dans la mesure où elle est proportionnée.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : la pratique est abusive parce qu'elle est grave (sans qualification)

✅ Correct : la pratique est abusive dès lors qu'elle exploite la position pour évincer un concurrent

❌ Erreur : pour autant qu'il porte de sur des données

✅ Correct : pour autant qu'il porte sur des données
