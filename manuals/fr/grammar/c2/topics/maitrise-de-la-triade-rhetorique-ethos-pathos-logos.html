Grammaire Française C2

Ethos, pathos, logos

Faire crédible, faire ressentir, démontrer.

🎯 Objectif de communication : Vous savez doser les trois appuis d'un discours.
Exemples en contexte
  • Exemple 1 : J'ai suivi ce dossier depuis l'origine (ethos) ; il engage des vies (pathos) ; les chiffres établissent le risque (logos). — Les trois appuis.
  • Exemple 2 : Ce n'est pas une opinion : trois audits concordent. — Logos dominant.
  • Exemple 3 : Nous avons tous vu ce que coûte l'attente. — Pathos sans emphase.

👀 Qu'observez-vous ?

Triade : ethos (crédibilité, expérience, désintéressement), pathos (émotion légitime, non manipulation), logos (preuve, chiffre, raisonnement). Le déséquilibre est le défaut : trop de logos ennuie, trop de pathos inquiète, trop d'ethos agace.

Élément / Structure Rôle en français Exemple d'application
ethos crédibilité j'ai suivi ce dossier depuis l'origine
pathos émotion légitime il engage des vies
logos preuve trois audits concordent
désintéressement ethos fort je n'ai rien à gagner à cette décision
émotion sans emphase pathos maîtrisé nous avons tous vu ce que coûte l'attente
preuve vérifiable logos fort les chiffres sont disponibles en annexe

Formule / Règle : Les trois appuis se renforcent : l'ethos rend le logos audible, le logos rend le pathos légitime. Un discours qui n'a que l'un des trois est soit ennuyeux (logos), soit suspect (pathos), soit vide (ethos).

★ Pourquoi c'est important

Le pathos est légitime quand il porte sur un enjeu réel et partagé ; il devient manipulation quand il est produit par la mise en scène plutôt que par le fait. La distinction n'est pas morale mais argumentative : un pathos fabriqué rend le logos inopérant.

💭 Pensez comme un francophone

L'ethos ne s'affirme pas, il s'établit : citer son expérience directement affaiblit, la laisser apparaître dans le traitement du dossier renforce.

🗣️ Note de prononciation

l'ethos /l‿e.tos/, le pathos /lə pa.tos/.

Banque d'exemples complémentaires
  • Ethos : J'ai examiné les trois scénarios ; deux se sont réalisés comme prévu.
  • Pathos : Derrière le calendrier, il y a des équipes qui ont tenu six mois.
  • Logos : Le surcoût est de 8 %, mesuré sur deux exercices.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : je suis quelqu'un d'expérimenté (ethos affirmé)

✅ Correct : j'ai suivi ce dossier depuis l'origine (ethos montré)

❌ Erreur : c'est inadmissible (pathos sans preuve)

✅ Correct : il engage des vies ; trois audits convergent
