Grammaire Française C2

La flexibilité morphosyntaxique

Changer de forme sans changer de sens.

🎯 Objectif de communication : Vous savez reformuler une phrase par plusieurs structures équivalentes.
Exemples en contexte
  • Exemple 1 : Le comité a décidé de reporter — Le report a été décidé par le comité. — Actif / passif.
  • Exemple 2 : Il est nécessaire que le texte soit signé — La signature du texte est nécessaire. — Verbe / nom.
  • Exemple 3 : On a constaté des irrégularités — Des irrégularités ont été constatées. — Impersonnel / passif.

👀 Qu'observez-vous ?

Flexibilité : actif / passif, verbe / nom, personnel / impersonnel, subordonnée / participiale, phrase / groupe nominal. Chaque transformation change le relief, non le contenu.

Formule / Règle : La flexibilité morphosyntaxique est la compétence qui permet d'enchaîner : quand une phrase commence par un nom, la suivante doit reprendre ce nom, ce qui oblige à choisir la forme compatible. Un texte rigide est un texte où chaque phrase a été écrite seule.

★ Pourquoi c'est important

L'équivalence n'est jamais parfaite : chaque transformation déplace le relief. La nominalisation efface l'agent, le passif déplace le thème, l'impersonnel dilue la responsabilité. Choisir, c'est assumer ce déplacement.

💭 Pensez comme un francophone

Le test de la flexibilité est la reformulation à l'envers : si l'on ne peut pas revenir à la forme initiale, c'est que le sens a changé. C'est le seul contrôle fiable.

Banque d'exemples complémentaires
  • Reformulation : La direction a suspendu les travaux → la suspension des travaux a été décidée.
  • Participiale : Après que le rapport a été lu → le rapport lu, la séance a repris.
  • Test : Peut-on revenir à « la direction a suspendu » ? Oui, avec le même contenu.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : des irrégularités ont été constatées (sans dire par qui)

✅ Correct : des irrégularités ont été constatées par le comité — si l'agent compte

❌ Erreur : il est nécessaire que le texte est signé

✅ Correct : il est nécessaire que le texte soit signé
