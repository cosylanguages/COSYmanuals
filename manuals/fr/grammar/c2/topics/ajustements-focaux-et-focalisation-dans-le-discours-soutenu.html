Les ajustements focaux

Déplacer le foyer d'un énoncé.

🎯 Objectif de communication : Vous savez déplacer le foyer d'une phrase par des moyens grammaticaux.
Exemples en contexte
  • Exemple 1 : C'est le calendrier qui, seul, explique le retard. — Foyer sur le sujet.
  • Exemple 2 : Le retard s'explique par le calendrier seul, non par la charge. — Foyer sur le complément.
  • Exemple 3 : Ce n'est pas la charge qui explique le retard, c'est le calendrier. — Foyer par contraste.

👀 Qu'observez-vous ?

Focalisation : c'est X qui, seul, ne… que, ce n'est pas X mais Y, quant à X, pour ce qui est de X. Le foyer est ce sur quoi porterait la négation.

Formule / Règle : Le foyer est la partie de l'énoncé que la négation aurait visée : « c'est le calendrier qui explique » — ce n'est pas la charge. Cette définition opérationnelle permet de vérifier qu'une phrase dit ce que l'on veut dire.

★ Pourquoi c'est important

Les ajustements focaux servent à corriger une attribution : « ce n'est pas la charge, c'est le calendrier ». Corriger est un acte argumentatif fort, car cela suppose que l'autre s'est trompé — d'où l'utilité des formes indirectes (quant à, pour ce qui est de).

💭 Pensez comme un francophone

Seul après le nom est le focalisateur le plus économique et le plus souvent mal placé : « le seul calendrier explique » change le sens, car la restriction ne porte plus sur le même élément.

🗣️ Note de prononciation

l'ajustement focal /l‿a.ʒys.tə.mɑ̃ fɔ.kal/, la topicalisation /la tɔ.pi.ka.li.za.sjɔ̃/.

Banque d'exemples complémentaires
  • Contraste : Ce n'est pas la méthode qui est en cause, mais la décision.
  • Restriction : Le retard ne tient qu'à un facteur : le calendrier.
  • Topicalisation : Quant à la charge, elle est stable depuis deux ans.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le seul calendrier explique le retard (place fautive)

✅ Correct : le calendrier seul explique le retard

❌ Erreur : c'est le calendrier qui explique le retard et la charge aussi (foyer contradictoire)

✅ Correct : c'est le calendrier, non la charge, qui explique le retard
