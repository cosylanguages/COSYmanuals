Antéposer pour médier

Placer en tête ce qui rassemble.

🎯 Objectif de communication : Vous savez antéposer dans une intervention de médiation.
Exemples en contexte
  • Exemple 1 : De ce constat partagé, deux conséquences se déduisent. — Antéposition fédératrice.
  • Exemple 2 : Sur ce point, les positions se rapprochent ; sur l'autre, elles divergent. — Cadrage par antéposition.
  • Exemple 3 : À cette question, le conseil devra répondre avant la clôture. — Antéposition d'obligation.

👀 Qu'observez-vous ?

Médiation : de ce constat partagé, sur ce point, à cette question, dans cette perspective, par cette décision. L'antéposition place en tête le terrain commun, non la thèse.

Formule / Règle : En médiation, l'antéposition a une fonction précise : elle place en tête ce qui est partagé, de sorte que la phrase parte de l'accord. Le désaccord vient ensuite, porté par une proposition principale — et il en paraît plus petit.

★ Pourquoi c'est important

Sur ce point… sur l'autre… est la figure de la cartographie : elle sépare les terrains et permet de constater l'accord sans nier le désaccord. C'est l'outil le plus utile d'une présidence de séance.

💭 Pensez comme un francophone

L'antéposition d'un accord (ce sur quoi nous sommes d'accord, c'est le diagnostic) est plus forte qu'un relevé : elle constitue l'accord comme point de départ du raisonnement, non comme un constat accessoire.

🗣️ Note de prononciation

l'antéposition /l‿ɑ̃.te.po.zi.sjɔ̃/, la médiation /la me.dja.sjɔ̃/.

Banque d'exemples complémentaires
  • Terrain : Sur la méthode, nous convergeons ; sur le calendrier, non.
  • Accord : Ce qui nous réunit, c'est le constat ; ce qui nous divise, c'est le rythme.
  • Obligation : À cette question, une réponse est due avant la clôture.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : je pense que nous sommes d'accord sur le diagnostic (médiation)

✅ Correct : ce sur quoi nous sommes d'accord, c'est le diagnostic

❌ Erreur : de ce constat partagé se déduisent deux conséquences (inversion fautive)

✅ Correct : de ce constat partagé se déduisent deux conséquences — vérifier l'accord : deux conséquences se déduisent
