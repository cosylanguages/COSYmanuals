Grammaire Française A2

Combiner COD et COI

Je le lui donne, je les leur envoie.

🎯 Objectif de communication : Vous savez employer deux pronoms compléments dans la même phrase.
Exemples en contexte
  • Exemple 1 : Je le lui donne. — COD le, puis COI lui.
  • Exemple 2 : Je les leur envoie. — COD les, puis COI leur.
  • Exemple 3 : Il ne me le dit pas. — me passe avant le, même à la négative.

👀 Qu'observez-vous ?

Ordre des pronoms : me, te, nous, vous avant le, la, les ; puis lui, leur en dernier. Formes contractées : me + le → me le, te + le → te le, lui + le → le lui.

Élément / Structure Rôle en français Exemple d'application
me / te / nous / vous + le / la / les premier groupe il me le donne
le / la / les + lui / leur second groupe je le lui donne
négation pronoms avant le verbe il ne me le dit pas
impératif affirmatif pronoms après le verbe donne-le-lui

Formule / Règle : Deux pronoms : le groupe me/te/nous/vous d'abord, puis le/la/les, puis lui/leur. À l'impératif affirmatif, tout passe après le verbe : donne-le-lui.

★ Pourquoi c'est important

Combiner deux pronoms évite les répétitions lourdes : sans cela, chaque phrase répète le nom et le destinataire.

💭 Pensez comme un francophone

Un francophone enchaîne : « je le lui ai déjà dit » se prononce presque en un mot.

🗣️ Note de prononciation

La suite le lui se prononce /lə lɥi/, sans pause.

Banque d'exemples complémentaires
  • Forme affirmative : Je le lui ai expliqué hier.
  • Forme interrogative : Tu le leur as dit ?
  • Forme négative : Ne le lui donne pas.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Je lui le donne.

✅ Correct : Je le lui donne.

❌ Erreur : Donne-lui-le.

✅ Correct : Donne-le-lui.
