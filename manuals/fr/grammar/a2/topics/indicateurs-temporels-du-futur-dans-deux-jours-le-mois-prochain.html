Grammaire Française A2

Les indicateurs de temps du futur

Dans deux jours, le mois prochain, bientôt, à l'avenir.

🎯 Objectif de communication : Vous savez dater un projet avec les marqueurs du futur.
Exemples en contexte
  • Exemple 1 : Je pars dans deux jours. — dans + durée situe dans le futur.
  • Exemple 2 : Le mois prochain, je commence un cours. — prochain s'accorde avec le nom.
  • Exemple 3 : À l'avenir, je ferai attention. — à l'avenir renvoie à un futur général.

👀 Qu'observez-vous ?

Quatre familles : distance comptée (dans + durée), période suivante (la semaine/le mois/l'année prochaine), proximité (bientôt, tout à l'heure), futur général (à l'avenir, plus tard).

1. Que signifie « dans trois jours » ?
dans + durée indique le futur ; il y a indique le passé.
2. Dit-on « le semaine prochaine » ?
Semaine est féminin : la semaine prochaine.
Élément / Structure Rôle en français Exemple d'application
dans + durée futur compté dans deux jours
prochain / prochaine période suivante le mois prochain
bientôt / prochainement proximité indéterminée bientôt
à l'avenir / plus tard futur général à l'avenir
dès que / aussitôt que point de départ futur dès que possible

Formule / Règle : Indicateurs futurs : dans + durée, prochain(e), bientôt, à l'avenir. Ils accompagnent le futur proche ou le futur simple et ne se confondent jamais avec il y a.

★ Pourquoi c'est important

Sans marqueur, un projet reste flou. Ces mots précisent le moment et rendent la phrase vérifiable.

💭 Pensez comme un francophone

Un francophone dit « la semaine prochaine » ou « semaine prochaine » sans article dans un agenda oral.

🗣️ Note de prononciation

prochain se prononce /pʁɔ.ʃɛ̃/. Dans « dans deux jours », la liaison est obligatoire : dans‿un.

Banque d'exemples complémentaires
  • Forme affirmative : Nous nous verrons la semaine prochaine.
  • Forme interrogative : Tu pars dans combien de jours ?
  • Forme négative : Je ne partirai pas avant le mois prochain.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le semaine prochaine

✅ Correct : la semaine prochaine

❌ Erreur : dans trois jours passés

✅ Correct : il y a trois jours
