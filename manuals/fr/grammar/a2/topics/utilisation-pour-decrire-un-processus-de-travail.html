Grammaire Française A2

Décrire un processus de travail

Le formulaire est rempli, puis signé, puis archivé.

🎯 Objectif de communication : Vous savez décrire les étapes d'une procédure au passif.
Exemples en contexte
  • Exemple 1 : Le formulaire est rempli par le client. — Première étape au passif.
  • Exemple 2 : Il est ensuite signé par le responsable. — ensuite marque l'ordre des étapes.
  • Exemple 3 : Enfin, le document est archivé. — enfin ferme la procédure.

👀 Qu'observez-vous ?

Un processus se décrit au passif avec des connecteurs d'ordre : d'abord, puis, ensuite, enfin. Chaque étape a un agent (par + personne) ou reste impersonnelle.

Élément / Structure Rôle en français Exemple d'application
d'abord + passif première étape d'abord, le dossier est ouvert
puis / ensuite + passif étapes suivantes puis il est vérifié
enfin + passif dernière étape enfin il est archivé
par + agent responsable de l'étape par le service comptable
en + durée délai de l'étape en deux jours

Formule / Règle : Processus : connecteurs d'ordre + passif au présent. L'agent (par + nom) précise qui agit ; sans agent, l'accent porte sur l'action.

★ Pourquoi c'est important

C'est la structure des procédures internes, des modes d'emploi et des consignes qualité : elle décrit ce qui est fait, pas qui le fait.

💭 Pensez comme un francophone

Un francophone alterne passif et « on » : « on remplit le formulaire, puis on le signe ».

🗣️ Note de prononciation

archivé se prononce /aʁ.ʃi.ve/. Le participe s'accorde si le sujet est féminin.

Banque d'exemples complémentaires
  • Forme affirmative : La demande est enregistrée puis transmise au service.
  • Forme interrogative : Par qui le dossier est-il validé ?
  • Forme négative : Le document n'est pas encore archivé.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : D'abord le dossier est ouvert, enfin il est vérifié, puis archivé.

✅ Correct : D'abord le dossier est ouvert, puis il est vérifié, enfin il est archivé.

❌ Erreur : Le dossier est vérifié du responsable.

✅ Correct : Le dossier est vérifié par le responsable.
