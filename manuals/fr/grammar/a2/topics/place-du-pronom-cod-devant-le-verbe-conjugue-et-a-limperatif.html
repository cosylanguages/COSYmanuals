La place du pronom COD

Je le prends / prends-le / ne le prends pas.

🎯 Objectif de communication : Vous savez placer le pronom COD devant le verbe conjugué et après l'impératif affirmatif.
Exemples en contexte
  • Exemple 1 : Je le prends tous les matins. — Devant un verbe conjugué : pronom avant.
  • Exemple 2 : Prends-le, il est à toi. — À l'impératif affirmatif : pronom après, avec trait d'union.
  • Exemple 3 : Ne le prends pas. — À l'impératif négatif : pronom avant.

👀 Qu'observez-vous ?

Trois positions : devant le verbe conjugué (je le vois), après l'impératif affirmatif (vois-le), avant l'impératif négatif (ne le vois pas). Avec un infinitif, le pronom se place devant l'infinitif (je vais le voir).

Élément / Structure Rôle en français Exemple d'application
verbe conjugué pronom avant je le vois
impératif affirmatif pronom après vois-le
impératif négatif pronom avant ne le vois pas
infinitif pronom devant l'infinitif je vais le voir
passé composé pronom avant l'auxiliaire je l'ai vu

Formule / Règle : Le pronom COD se place devant le verbe conjugué et devant l'infinitif, mais après un impératif affirmatif, avec un trait d'union.

★ Pourquoi c'est important

La place du pronom est l'erreur la plus visible : « je vois le » n'existe pas, alors que « je le vois » est la norme.

💭 Pensez comme un francophone

Un francophone ne sépare jamais le pronom de son verbe : ils forment un bloc.

🗣️ Note de prononciation

Le pronom se lie au verbe : je le‿ai vu /ʒə le t‿ɛ vy/ (avec le t de liaison).

Banque d'exemples complémentaires
  • Forme affirmative : Je vais le prendre demain.
  • Forme interrogative : Tu le prends ?
  • Forme négative : Ne le prends pas maintenant.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Je vais prendre le.

✅ Correct : Je vais le prendre.

❌ Erreur : Prends le.

✅ Correct : Prends-le.
