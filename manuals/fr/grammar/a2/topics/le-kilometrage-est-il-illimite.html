Poser une question sur un contrat

Le kilométrage est-il illimité ?

🎯 Objectif de communication : Vous savez vérifier les conditions d'une location.
Exemples en contexte
  • Exemple 1 : Le kilométrage est-il illimité ? — Question avec inversion et attribut.
  • Exemple 2 : Non, il est limité à 200 kilomètres par jour. — Réponse avec limite.
  • Exemple 3 : L'assurance est-elle incluse ? — Autre question de contrat.

👀 Qu'observez-vous ?

Question : sujet + est-il / est-elle + attribut ? (le kilométrage est-il illimité). Réponse : oui, non, il est limité à + nombre.

Formule / Règle : Vérifier un contrat : question avec inversion (est-il, est-elle), réponse avec être limité à, être inclus dans, supplément de.

★ Pourquoi c'est important

Ces questions évitent les mauvaises surprises à la restitution : le contrat se lit avant la signature, pas après.

💭 Pensez comme un francophone

Un francophone demande « c'est illimité ? » dans un contexte familier.

🗣️ Note de prononciation

kilométrage se prononce /ki.lɔ.me.tʁaʒ/.

Banque d'exemples complémentaires

  • Forme interrogative : Le kilométrage est-il illimité ?
  • Forme négative : L'assurance n'est pas incluse dans le prix.
