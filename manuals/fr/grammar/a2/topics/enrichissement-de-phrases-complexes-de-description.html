Grammaire Française A2

Enrichir une phrase de description

Du nom à la relative : ajouter sans répéter.

🎯 Objectif de communication : Vous savez allonger une phrase simple avec des relatives et des compléments.
Exemples en contexte
  • Exemple 1 : La maison est ancienne. → La maison que nous avons visitée est ancienne. — Relative pour préciser.
  • Exemple 2 : C'est un village. → C'est un village qui domine la mer. — qui + verbe pour caractériser.
  • Exemple 3 : Le musée est fermé. → Le musée où nous devions aller est fermé. — où pour situer.

👀 Qu'observez-vous ?

Trois outils : la relative (qui, que, où), le complément de nom (la maison du village), l'adjectif (une maison ancienne). Ils s'ajoutent sans créer de nouvelle phrase.

Élément / Structure Rôle en français Exemple d'application
relative avec qui sujet un village qui domine la mer
relative avec que objet la maison que nous avons visitée
relative avec où lieu ou temps le musée où nous devions aller
complément de nom précision la maison du village
adjectif qualité une maison ancienne

Formule / Règle : Enrichir une description : adjectif (qualité), complément de nom (précision), relative (information développée). Chaque outil ajoute une couche sans créer de phrase nouvelle.

★ Pourquoi c'est important

Une description riche se construit par couches : elle évite la juxtaposition de phrases courtes et donne une impression de maîtrise.

💭 Pensez comme un francophone

Un francophone enchaîne naturellement deux relatives : « la maison que nous avons visitée, qui domine la mer, est ancienne ».

🗣️ Note de prononciation

La relative se prononce sans pause : la maison‿que /la mɛ.zɔ̃ kə/.

Banque d'exemples complémentaires
  • Forme affirmative : C'est un quartier qui a beaucoup changé.
  • Forme interrogative : C'est la maison que tu préfères ?
  • Forme négative : Ce n'est pas le village où j'ai grandi.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : La maison que nous avons visité (accord).

✅ Correct : La maison que nous avons visitée.

❌ Erreur : Le village qui nous avons visité.

✅ Correct : Le village que nous avons visité.
