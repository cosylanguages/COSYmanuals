Grammaire Française A2

Du possessif au pronom possessif

Mon sac → le mien, ta veste → la tienne.

🎯 Objectif de communication : Vous savez remplacer adjectif possessif + nom par le pronom possessif.
Exemples en contexte
  • Exemple 1 : Mon sac est ici, le tien est là-bas. — mon sac → le mien / le tien.
  • Exemple 2 : Ta veste est neuve, la mienne est vieille. — ta veste → la mienne.
  • Exemple 3 : Leurs clés sont sur la table, les nôtres aussi. — leurs clés → les nôtres.

👀 Qu'observez-vous ?

Le pronom possessif reprend l'adjectif et le nom : le mien, la mienne, les miens, les miennes ; le tien… ; le sien… ; le nôtre… ; le vôtre… ; le leur… L'article s'accorde avec le nom remplacé.

Élément / Structure Rôle en français Exemple d'application
le mien / la mienne première personne mon livre → le mien
le tien / la tienne deuxième personne ton livre → le tien
le sien / la sienne troisième personne son livre → le sien
le nôtre / la nôtre nous notre livre → le nôtre
le vôtre / la vôtre vous votre livre → le vôtre
le leur / la leur ils / elles leur livre → le leur

Formule / Règle : Pronom possessif = article défini + forme possessive, accordé avec le nom remplacé : le mien, la mienne, les miens, les miennes.

★ Pourquoi c'est important

Le pronom possessif évite la répétition du nom tout en gardant l'information d'appartenance : « ton sac est plus léger que le mien ».

💭 Pensez comme un francophone

Un francophone l'emploie surtout à l'écrit et dans les comparaisons ; à l'oral, il préfère souvent répéter le nom.

🗣️ Note de prononciation

nôtre et vôtre ont un accent circonflexe, contrairement aux adjectifs notre et votre.

Banque d'exemples complémentaires
  • Forme affirmative : Ma voiture est ancienne, la sienne est neuve.
  • Forme interrogative : C'est le tien, ce manteau ?
  • Forme négative : Ce n'est pas le mien.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Ce sac est mon.

✅ Correct : Ce sac est le mien.

❌ Erreur : Ta veste est plus grande que le mien.

✅ Correct : Ta veste est plus grande que la mienne.
