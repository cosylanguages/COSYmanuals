Le superlatif

Le plus grand, la moins chère, les plus proches.

🎯 Objectif de communication : Vous savez situer un élément au sommet d'un groupe.
Exemples en contexte
  • Exemple 1 : C'est le plus proche du métro. — Superlatif de supériorité, masculin singulier.
  • Exemple 2 : C'est la moins chère du quartier. — Superlatif d'infériorité, féminin.
  • Exemple 3 : Ce sont les plus grands appartements. — Accord au pluriel.

👀 Qu'observez-vous ?

Superlatif = le / la / les + plus / moins + adjectif. Le complément du groupe se construit avec de (de la ville, du quartier), rarement avec dans.

Élément / Structure Rôle en français Exemple d'application
le / la / les + plus + adjectif supériorité le plus grand
le / la / les + moins + adjectif infériorité la moins chère
+ de + groupe complément le plus grand du quartier
meilleur / le mieux irréguliers le meilleur choix
accord avec le nom les plus proches

Formule / Règle : Superlatif : article défini + plus / moins + adjectif, accordé avec le nom. Le groupe de comparaison se construit avec de.

★ Pourquoi c'est important

C'est la structure de la recommandation absolue : « le meilleur choix », « le moins cher du quartier ».

💭 Pensez comme un francophone

Un francophone ajoute souvent « de loin » pour renforcer : « c'est de loin le plus calme ».

🗣️ Note de prononciation

plus se prononce /ply/ dans le superlatif : le plus grand /lə ply ɡʁɑ̃/.

Banque d'exemples complémentaires
  • Forme affirmative : C'est la meilleure solution du dossier.
  • Forme interrogative : Quel est le moins cher ?
  • Forme négative : Ce n'est pas le plus pratique.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le plus bon

✅ Correct : le meilleur

❌ Erreur : le plus grand que le quartier

✅ Correct : le plus grand du quartier
