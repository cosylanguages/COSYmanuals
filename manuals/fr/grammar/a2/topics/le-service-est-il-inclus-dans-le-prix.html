Demander si un service est inclus

Le service est-il inclus dans le prix ?

🎯 Objectif de communication : Vous savez vérifier ce que couvre un prix.
Exemples en contexte
  • Exemple 1 : Le service est-il inclus dans le prix ? — Question sur l'inclusion.
  • Exemple 2 : Oui, le service est compris. — Réponse avec compris.
  • Exemple 3 : Non, il y a un supplément de quinze pour cent. — Réponse avec supplément.

👀 Qu'observez-vous ?

Question : sujet + est-il + inclus dans + nom ? Réponse : être inclus / compris dans, ou supplément de + montant.

Formule / Règle : Inclusion : est-il inclus dans ? Réponse : inclus / compris dans, ou en supplément, supplément de.

★ Pourquoi c'est important

Cette vérification évite de payer deux fois le même service et permet de comparer deux offres à armes égales.

💭 Pensez comme un francophone

Un francophone demande « c'est compris ? » en montrant la note.

🗣️ Note de prononciation

inclus se prononce /ɛ̃.kly/, supplément /sy.ple.mɑ̃/.
