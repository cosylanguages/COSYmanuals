Grammaire Française A2

Trop ou pas assez

Trop cher / pas assez cher.

🎯 Objectif de communication : Vous savez exprimer l'excès et l'insuffisance.
Exemples en contexte
  • Exemple 1 : Ce logement est trop cher. — trop + adjectif : excès.
  • Exemple 2 : Il n'est pas assez grand. — pas assez + adjectif : insuffisance.
  • Exemple 3 : Il fait trop chaud pour travailler. — trop + adjectif + pour + infinitif.

👀 Qu'observez-vous ?

trop + adjectif exprime l'excès ; pas assez + adjectif exprime l'insuffisance. Les deux peuvent se terminer par pour + infinitif (trop chaud pour sortir).

Élément / Structure Rôle en français Exemple d'application
trop + adjectif excès trop cher
pas assez + adjectif insuffisance pas assez grand
trop + adjectif + pour + infinitif excès bloquant trop chaud pour sortir
assez + adjectif suffisance assez grand
suffisamment / trop peu variantes suffisamment grand

Formule / Règle : trop = excès ; pas assez = insuffisance ; assez = suffisance. Ces trois degrés servent à justifier un refus ou une demande.

★ Pourquoi c'est important

Ces formules sont celles de la négociation : « trop cher » ouvre une discussion sur le prix, « pas assez grand » sur la surface.

💭 Pensez comme un francophone

Un francophone dit « c'est trop » sans adjectif quand le contexte est clair.

🗣️ Note de prononciation

trop se prononce /tʁo/, assez /a.se/.

Banque d'exemples complémentaires
  • Forme affirmative : Cet appartement est trop petit pour nous.
  • Forme interrogative : Il n'est pas assez grand ?
  • Forme négative : Ce n'est pas trop cher.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Il est pas assez de grand.

✅ Correct : Il n'est pas assez grand.

❌ Erreur : Trop de cher.

✅ Correct : Trop cher.
