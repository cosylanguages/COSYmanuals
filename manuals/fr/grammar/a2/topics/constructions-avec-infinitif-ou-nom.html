Grammaire Française A2

Verbe + infinitif ou verbe + nom

J'aime lire / j'aime la lecture.

🎯 Objectif de communication : Vous savez choisir entre infinitif et nom après un verbe de goût ou d'opinion.
Exemples en contexte
  • Exemple 1 : J'aime lire le soir. — Même sujet : infinitif.
  • Exemple 2 : J'aime la lecture. — Nom : le goût porte sur une activité en général.
  • Exemple 3 : Je préfère partir tôt. — préférer + infinitif, même sujet.

👀 Qu'observez-vous ?

Infinitif quand le sujet du second verbe est le même (j'aime lire) ; nom quand on désigne une chose ou une activité en général (j'aime la lecture). Certains verbes n'acceptent qu'un nom (je préfère le thé).

1. Quand emploie-t-on l'infinitif ?
J'aime lire : c'est moi qui lis.

Le goût général se dit avec l'infinitif sans article.
Élément / Structure Rôle en français Exemple d'application
verbe de goût + infinitif même sujet j'aime danser
verbe de goût + nom chose ou activité générale j'aime la danse
préférer + infinitif choix d'action je préfère partir
préférer + nom choix d'objet je préfère le thé
détester + infinitif rejet d'une action je déteste attendre

Formule / Règle : Après un verbe de goût : infinitif pour une action du même sujet, nom pour une activité ou un objet. L'article disparaît devant l'infinitif.

★ Pourquoi c'est important

Le choix change le sens : « j'aime lire » parle d'une habitude, « j'aime la lecture » d'un domaine.

💭 Pensez comme un francophone

Un francophone alterne sans y penser, souvent avec une préférence pour l'infinitif à l'oral.

🗣️ Note de prononciation

L'infinitif après aimer se prononce sans pause : j'aime‿écouter /ʒɛ.m‿e.ku.te/.

Banque d'exemples complémentaires
  • Forme affirmative : J'aime beaucoup cuisiner.
  • Forme interrogative : Tu aimes la musique classique ?
  • Forme négative : Je n'aime pas attendre.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : J'aime le lire.

✅ Correct : J'aime lire.

❌ Erreur : Je préfère de partir.

✅ Correct : Je préfère partir.
