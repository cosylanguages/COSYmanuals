Grammaire Française A2

Exprimer un but : pour, afin de, pour que

Pour réussir, afin de progresser, pour que tu comprennes.

🎯 Objectif de communication : Vous savez exprimer un but avec pour, afin de et pour que.
Exemples en contexte
  • Exemple 1 : J'étudie pour réussir. — pour + infinitif, même sujet.
  • Exemple 2 : Je travaille afin de progresser. — afin de + infinitif, registre plus soutenu.
  • Exemple 3 : Je parle lentement pour que tu comprennes. — pour que + subjonctif, deux sujets différents.

👀 Qu'observez-vous ?

Même sujet : pour + infinitif ou afin de + infinitif. Sujets différents : pour que + subjonctif. Afin que est la variante soutenue de pour que.

Élément / Structure Rôle en français Exemple d'application
pour + infinitif même sujet je travaille pour réussir
afin de + infinitif même sujet, soutenu afin de progresser
pour que + subjonctif sujets différents pour que tu comprennes
afin que + subjonctif sujets différents, soutenu afin que nous partions
dans le but de registre administratif dans le but d'obtenir

Formule / Règle : But : pour / afin de + infinitif quand le sujet est le même ; pour que / afin que + subjonctif quand les sujets diffèrent.

★ Pourquoi c'est important

Le but structure tout argumentaire : il explique pourquoi on agit, ce qui est la question la plus fréquente d'un entretien.

💭 Pensez comme un francophone

Un francophone dit « pour » dans neuf cas sur dix ; afin de appartient à l'écrit soigné.

🗣️ Note de prononciation

afin de se lie : afin‿de /a.fɛ̃ də/.

Banque d'exemples complémentaires
  • Forme affirmative : Je révise afin de réussir l'examen.
  • Forme interrogative : Pourquoi travailles-tu autant ?
  • Forme négative : Je parle doucement pour ne pas te déranger.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Je travaille pour que je réussisse.

✅ Correct : Je travaille pour réussir.

❌ Erreur : pour que tu comprends

✅ Correct : pour que tu comprennes
