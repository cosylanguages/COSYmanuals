L'accord de tout

Tout, toute, tous, toutes : quatre formes, quatre emplois.

🎯 Objectif de communication : Vous savez accorder tout et distinguer adjectif, pronom et adverbe.
Exemples en contexte
  • Exemple 1 : Tous les articles sont en promotion. — Adjectif : accord avec le nom.
  • Exemple 2 : Tout est en solde. — Pronom : accord avec ce qu'il reprend.
  • Exemple 3 : Elles sont toutes venues. — Pronom : accord au féminin pluriel.

👀 Qu'observez-vous ?

Adjectif : tout, toute, tous, toutes + nom. Pronom : tous, toutes (accord avec le groupe repris). Adverbe : tout invariable devant un adjectif (tout seul, tout petit).

Élément / Structure Rôle en français Exemple d'application
tout + nom masculin adjectif tout le quartier
toute + nom féminin adjectif toute la journée
tous les + nom pluriel adjectif tous les jours
toutes les + nom féminin pluriel adjectif toutes les semaines
tous / toutes pronom ils sont tous venus
tout + adjectif adverbe invariable tout petit

Formule / Règle : tout adjectif s'accorde ; tout pronom s'accorde avec le groupe repris ; tout adverbe reste invariable. tous se prononce /tus/ comme pronom.

★ Pourquoi c'est important

Ce petit mot revient dans chaque règle et chaque quantité : une erreur d'accord se voit immédiatement.

💭 Pensez comme un francophone

Un francophone dit « tous » /tus/ quand il est seul et « tous les » /tu le/ devant un nom.

🗣️ Note de prononciation

tous pronom /tus/, tous les /tu le/, toutes /tut/.

Banque d'exemples complémentaires
  • Forme affirmative : Toutes les chambres sont réservées.
  • Forme interrogative : Tous les modèles sont disponibles ?
  • Forme négative : Tous les articles ne sont pas en solde.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Tout les articles

✅ Correct : Tous les articles

❌ Erreur : Elles sont tout venues.

✅ Correct : Elles sont toutes venues.
