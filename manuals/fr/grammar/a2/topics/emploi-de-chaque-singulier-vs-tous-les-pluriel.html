Grammaire Française A2

Chaque ou tous les

Chaque client / tous les clients.

🎯 Objectif de communication : Vous savez choisir entre chaque et tous les selon le sens.
Exemples en contexte
  • Exemple 1 : Chaque client reçoit un ticket. — chaque + nom singulier, vision individuelle.
  • Exemple 2 : Tous les clients reçoivent un ticket. — tous les + nom pluriel, vision globale.
  • Exemple 3 : Chaque semaine, je vérifie mon compte. — chaque + unité de temps.

👀 Qu'observez-vous ?

chaque est toujours suivi d'un nom singulier et le verbe reste au singulier ; tous les / toutes les demandent un pluriel et le verbe au pluriel.

Élément / Structure Rôle en français Exemple d'application
chaque + singulier un par un chaque client
tous les / toutes les + pluriel ensemble tous les clients
chaque + temps répétition chaque semaine
tous les + temps répétition globale tous les lundis
chacun / chacune pronom chacun reçoit un ticket

Formule / Règle : chaque + singulier (insistance sur l'individu) ; tous les + pluriel (insistance sur l'ensemble). chacun et chacune remplacent chaque + nom.

★ Pourquoi c'est important

Le choix change la règle annoncée : « chaque client reçoit » oblige individuellement, « tous les clients reçoivent » décrit le groupe.

💭 Pensez comme un francophone

Un francophone emploie « chaque » pour insister : « chaque dossier est vérifié, un par un ».

🗣️ Note de prononciation

chaque se prononce /ʃak/, chacun /ʃa.kœ̃/.

Banque d'exemples complémentaires
  • Forme affirmative : Chaque dossier est vérifié séparément.
  • Forme interrogative : Chaque client reçoit-il un ticket ?
  • Forme négative : Tous les modèles ne sont pas disponibles.
