Grammaire Française A2

Demander le prix d'un service

Combien facturez-vous pour le service de… ?

🎯 Objectif de communication : Vous savez demander un tarif de prestation.
Exemples en contexte
  • Exemple 1 : Combien facturez-vous pour le service de livraison ? — Question avec facturer.
  • Exemple 2 : Nous facturons vingt euros pour la livraison. — Réponse avec facturer + prix.
  • Exemple 3 : Le service est gratuit au-delà de cinquante euros. — Condition de gratuité.

👀 Qu'observez-vous ?

Question : combien facturez-vous pour + nom ? Réponse : nous facturons + prix + pour + nom, ou le service est gratuit au-delà de.

Formule / Règle : Tarif d'un service : combien facturez-vous pour + nom ? Réponse : facturer + prix, être gratuit au-delà de, forfait de.

★ Pourquoi c'est important

Cette question permet de comparer deux prestataires sur le même service, sans surprise sur la facture finale.

💭 Pensez comme un francophone

Un francophone demande « c'est combien, la livraison ? ».

🗣️ Note de prononciation

facturez se prononce /fak.ty.ʁe/, forfait /fɔʁ.fɛ/.

Banque d'exemples complémentaires
  • Forme affirmative : Nous facturons quinze euros pour la livraison.
  • Forme interrogative : Combien facturez-vous pour ce service ?
  • Forme négative : Nous ne facturons pas la livraison.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Combien facturez-vous le service ?

✅ Correct : Combien facturez-vous pour le service ?

❌ Erreur : Nous facturons de vingt euros.

✅ Correct : Nous facturons vingt euros.
