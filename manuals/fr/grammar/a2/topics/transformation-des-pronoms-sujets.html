Grammaire Française A2

Transformer les pronoms au discours indirect

« Je viens » → il dit qu'il vient ; « tu viens » → il dit que je viens.

🎯 Objectif de communication : Vous savez adapter les pronoms quand on rapporte des paroles.
Exemples en contexte
  • Exemple 1 : « Je suis prêt » → Il dit qu'il est prêt. — je devient il quand un homme parle.
  • Exemple 2 : « Tu es prêt » → Il me dit que je suis prêt. — tu devient je quand on s'adresse à moi.
  • Exemple 3 : « Nous partons » → Ils disent qu'ils partent. — nous devient ils.

👀 Qu'observez-vous ?

Trois transformations : je → il/elle, tu → je (ou il/elle selon le destinataire), nous → ils/elles. Les possessifs suivent : mon → son, ton → mon.

Élément / Structure Rôle en français Exemple d'application
je → il / elle le locuteur devient troisième personne « je viens » → il dit qu'il vient
tu → je le destinataire devient locuteur « tu viens » → il me dit que je viens
nous → ils / elles le groupe devient troisième personne « nous partons » → ils disent qu'ils partent
mon / ma / mes → son / sa / ses possessif « mon frère » → son frère
ton / ta / tes → mon / ma / mes possessif « ton frère » → mon frère

Formule / Règle : Au discours indirect, les pronoms et les possessifs se décalent selon qui parle : je → il, tu → je, nous → ils, mon → son, ton → mon.

★ Pourquoi c'est important

Sans cette transformation, on attribue à soi-même les paroles d'un autre : « il dit que je viens » peut signifier deux choses opposées.

💭 Pensez comme un francophone

Un francophone marque souvent le changement par « soi-disant » ou « paraît-il » quand le référent est ambigu.

🗣️ Note de prononciation

Les formes élidées se suivent : qu'il, qu'elle, qu'on.

Banque d'exemples complémentaires
  • Forme affirmative : Elle dit qu'elle a fini son rapport.
  • Forme interrogative : Il demande si je peux venir avec mon frère.
  • Forme négative : Ils disent qu'ils ne partent pas.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Paul dit que je viens (quand Paul parle de lui).

✅ Correct : Paul dit qu'il vient.

❌ Erreur : Il dit que mon frère est là (quand il parle de son frère).

✅ Correct : Il dit que son frère est là.
