L'accord du pronom avec le nom remplacé

Le mien, la mienne, les miens, les miennes.

🎯 Objectif de communication : Vous savez accorder un pronom avec le nom qu'il remplace, et non avec le possesseur.
Exemples en contexte
  • Exemple 1 : Mon frère et ma sœur : le mien est grand, la mienne est petite. — Le pronom suit le genre du nom remplacé.
  • Exemple 2 : Tes clés et ton portefeuille : les tiennes sont ici. — Pluriel : les tiennes.
  • Exemple 3 : Leur maison est loin, la nôtre est proche. — Accord avec maison, féminin.

👀 Qu'observez-vous ?

Le pronom s'accorde en genre et en nombre avec le nom qu'il remplace, jamais avec la personne qui possède. C'est la règle commune aux pronoms possessifs et démonstratifs.

Élément / Structure Rôle en français Exemple d'application
le mien nom masculin singulier mon livre → le mien
la mienne nom féminin singulier ma veste → la mienne
les miens nom masculin pluriel mes livres → les miens
les miennes nom féminin pluriel mes clés → les miennes
accord avec le nom jamais avec le possesseur une femme dit le mien pour son frère

Formule / Règle : Le pronom possessif s'accorde avec le nom remplacé : masculin/féminin, singulier/pluriel. Le sexe du possesseur n'intervient jamais.

★ Pourquoi c'est important

C'est la source d'erreur la plus fréquente : on accorde avec soi-même au lieu d'accorder avec l'objet.

💭 Pensez comme un francophone

Un francophone ne réfléchit pas : il entend « ma veste… la mienne » comme un bloc.

🗣️ Note de prononciation

mienne se prononce /mjɛn/, tiens /tjɛ̃/, tiennes /tjɛn/.

Banque d'exemples complémentaires
  • Forme affirmative : Ses affaires sont rangées, les miennes sont en désordre.
  • Forme interrogative : Ce sont les tiennes, ces clés ?
  • Forme négative : Ce ne sont pas les nôtres.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Mes clés ? Les miens sont ici.

✅ Correct : Mes clés ? Les miennes sont ici.

❌ Erreur : Une femme dit toujours « la mienne ».

✅ Correct : Une femme dit « le mien » pour un nom masculin.
