Grammaire Française A2

Une première approche du futur simple

Dans un an, je serai…

🎯 Objectif de communication : Vous savez exprimer un projet lointain avec le futur simple.
Exemples en contexte
  • Exemple 1 : Dans un an, je serai étudiant. — Futur simple pour un état à venir.
  • Exemple 2 : L'année prochaine, nous partirons en Espagne. — Projet daté.
  • Exemple 3 : Un jour, tu comprendras. — Prédiction.

👀 Qu'observez-vous ?

Le futur simple exprime un projet lointain, une prédiction ou une promesse. Il se forme sur l'infinitif + -ai, -as, -a, -ons, -ez, -ont.

dans + durée projet daté dans un an
l'année prochaine période future l'année prochaine
infinitif + terminaisons formation je parlerai
prédiction avenir incertain un jour, tu comprendras
promesse engagement je te téléphonerai

Formule / Règle : Futur simple : infinitif + -ai, -as, -a, -ons, -ez, -ont. Pour un projet lointain, une prédiction ou une promesse. Le futur proche reste réservé à l'immédiat.

★ Pourquoi c'est important

C'est le temps des projets de vie : études, déménagement, voyage. Il donne un cadre au discours sur l'avenir.

💭 Pensez comme un francophone

Un francophone alterne futur proche et futur simple selon l'urgence : « je vais partir » / « je partirai ».

🗣️ Note de prononciation

serai se prononce /sə.ʁe/, parlerai /paʁ.lə.ʁe/.

Banque d'exemples complémentaires
  • Forme affirmative : Dans cinq ans, j'aurai un travail stable.
  • Forme interrogative : Tu viendras avec nous l'année prochaine ?
  • Forme négative : Je ne partirai pas avant l'été.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Dans un an, je vais être étudiant (possible mais moins naturel pour un état lointain).

✅ Correct : Dans un an, je serai étudiant.

❌ Erreur : Je serais étudiant dans un an (conditionnel).

✅ Correct : Je serai étudiant dans un an.
