Grammaire Française A2

Cette place est-elle réservée ?

Question avec inversion et accord de l'attribut.

🎯 Objectif de communication : Vous savez demander si une place est libre.
Exemples en contexte
  • Exemple 1 : Cette place est-elle réservée ? — Inversion avec est-elle, accord au féminin.
  • Exemple 2 : Non, elle est libre. — Réponse courte avec pronom.
  • Exemple 3 : Oui, ce siège est réservé. — Accord au masculin avec siège.

👀 Qu'observez-vous ?

Question : nom + est-il / est-elle + attribut ? L'attribut s'accorde avec le nom : la place est-elle réservée, le siège est-il réservé.

Formule / Règle : Demander une place : nom + est-il/est-elle + réservé(e) ? L'accord de l'attribut suit le nom. La réponse reprend le pronom : elle est libre.

★ Pourquoi c'est important

Cette question se pose au théâtre, dans le train ou dans une salle d'attente : la forme polie précède toujours.

💭 Pensez comme un francophone

Un francophone dit « c'est libre ? » en montrant la place.

🗣️ Note de prononciation

réservée se prononce /ʁe.zɛʁ.ve/.

Banque d'exemples complémentaires
  • Forme affirmative : Cette place est réservée.
  • Forme interrogative : Cette place est-elle réservée ?
  • Forme négative : Cette place n'est pas réservée.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Cette place est-il réservé ?

✅ Correct : Cette place est-elle réservée ?

❌ Erreur : Elle est libre, la place ?

✅ Correct : Oui, elle est libre.
