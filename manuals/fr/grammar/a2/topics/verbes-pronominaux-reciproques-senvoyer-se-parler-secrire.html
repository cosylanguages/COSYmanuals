Grammaire Française A2

Les verbes pronominaux réciproques

Ils s'écrivent, elles se parlent, nous nous envoyons.

🎯 Objectif de communication : Vous savez exprimer une action mutuelle entre plusieurs personnes.
Exemples en contexte
  • Exemple 1 : Ils s'écrivent chaque semaine. — s'écrire : action mutuelle.
  • Exemple 2 : Elles se parlent tous les jours. — se parler : chacun parle à l'autre.
  • Exemple 3 : Nous nous envoyons des photos. — s'envoyer : échange réciproque.

👀 Qu'observez-vous ?

Les verbes pronominaux réciproques expriment une action mutuelle ; le pronom s'accorde avec le sujet pluriel : nous nous, vous vous, ils se, elles se.

1. Quel sujet est nécessaire pour un réciproque ?
Ils s'écrivent : au moins deux personnes.
2. Que signifie « ils se parlent » ?
La réciprocité remplace le réfléchi.
Élément / Structure Rôle en français Exemple d'application
nous nous écrivons réciprocité à deux ou plus nous nous écrivons
vous vous parlez réciprocité vous vous parlez souvent
ils s'envoient réciprocité ils s'envoient des messages
elles se téléphonent réciprocité elles se téléphonent
l'un l'autre / les uns les autres insistance ils s'aident l'un l'autre

Formule / Règle : Réciproque : pronom réfléchi accordé au sujet pluriel. Le sens est mutuel, sauf si le verbe ne peut pas être réciproque (se laver reste réfléchi).

★ Pourquoi c'est important

Ces verbes décrivent la vie sociale : se parler, s'écrire, s'envoyer, se voir, s'aider. Ils condensent deux actions en une.

💭 Pensez comme un francophone

Un francophone ajoute « l'un l'autre » pour lever l'ambiguïté avec le réfléchi.

🗣️ Note de prononciation

s'écrivent se prononce /se.kʁiv/, avec le pronom soudé au verbe.

Banque d'exemples complémentaires
  • Forme affirmative : Ils se téléphonent tous les dimanches.
  • Forme interrogative : Vous vous écrivez souvent ?
  • Forme négative : Elles ne se parlent plus.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Ils se écrit.

✅ Correct : Ils s'écrivent.

❌ Erreur : Nous se parlons.

✅ Correct : Nous nous parlons.
