Grammaire Française A2

Demander un plat sans un ingrédient

Pouvez-vous préparer ce plat sans crème ?

🎯 Objectif de communication : Vous savez demander une adaptation d'un plat.
Exemples en contexte
  • Exemple 1 : Pouvez-vous préparer ce plat sans crème ? — Demande avec sans + nom.
  • Exemple 2 : Oui, nous pouvons le faire sans beurre. — Réponse avec le pronom le.
  • Exemple 3 : Malheureusement, la sauce contient déjà de la crème. — Refus avec justification.

👀 Qu'observez-vous ?

Demande : pouvez-vous + infinitif + sans + nom ? sans indique l'absence d'un ingrédient. La réponse reprend avec le pronom COD : le faire sans.

Formule / Règle : Adapter un plat : pouvez-vous le préparer sans + nom ? Réponse avec le pronom COD (le faire sans) ou un refus justifié (la sauce contient déjà…).

★ Pourquoi c'est important

Cette demande est fréquente pour raison médicale ou habitude alimentaire : elle doit être précise pour être satisfaite.

💭 Pensez comme un francophone

Un francophone dit « c'est possible sans crème ? ».

🗣️ Note de prononciation

sans se prononce /sɑ̃/, avec liaison obligatoire : sans‿crème /sɑ̃ kʁɛm/.

Banque d'exemples complémentaires
  • Forme affirmative : Je voudrais ce plat sans sauce.
  • Forme interrogative : Pouvez-vous le préparer sans crème ?
  • Forme négative : Ce n'est pas possible sans beurre.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Pouvez-vous préparer sans de crème ?

✅ Correct : Pouvez-vous préparer sans crème ?

❌ Erreur : Nous pouvons faire le sans crème.

✅ Correct : Nous pouvons le faire sans crème.
