Grammaire Française A2

Le présent de description

Sur la photo, il y a… on voit…

🎯 Objectif de communication : Vous savez décrire une image au présent.
Exemples en contexte
  • Exemple 1 : Sur la photo, il y a trois personnes. — Présent de description.
  • Exemple 2 : Elles portent des manteaux. — Présent d'état et d'action.
  • Exemple 3 : La scène se passe dans une rue. — Présent de situation.

👀 Qu'observez-vous ?

La description d'une image emploie le présent : il y a (existence), on voit / on aperçoit (perception), porter / tenir (action représentée), se passer (situation).

Élément / Structure Rôle en français Exemple d'application
il y a existence il y a trois personnes
on voit / on aperçoit perception on voit la mer
porter / tenir action représentée elles portent des manteaux
se passer situation la scène se passe dans une rue
sembler / paraître interprétation prudente ils semblent heureux

Formule / Règle : Description au présent : il y a, on voit, porter, se passer, sembler. Le présent fige l'image, le passé raconterait une histoire.

★ Pourquoi c'est important

Choisir le présent de description évite de raconter au passé une scène qui est sous les yeux.

💭 Pensez comme un francophone

Un francophone alterne description au présent et interprétation : « ils semblent heureux ».

🗣️ Note de prononciation

il y a se lie : il y‿a /i.l.ja/.

Banque d'exemples complémentaires
  • Forme affirmative : Sur l'image, il y a un marché.
  • Forme interrogative : Qu'est-ce qu'on voit sur la photo ?
  • Forme négative : On ne voit pas le visage.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Sur la photo, il y avait trois personnes.

✅ Correct : Sur la photo, il y a trois personnes.

❌ Erreur : La scène s'est passée dans une rue (photo).

✅ Correct : La scène se passe dans une rue.
