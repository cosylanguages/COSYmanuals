Grammaire Française A1

Une table pour deux, s'il vous plaît

Réserver une table en arrivant au restaurant.

🎯 Objectif de communication : Vous savez demander une table et donner le nombre de personnes.
Exemples en contexte
  • Exemple 1 : Une table pour deux personnes, s'il vous plaît. — Demande simple et polie.
  • Exemple 2 : Nous sommes trois. — Indication du nombre.
  • Exemple 3 : Avez-vous réservé ? — Question d'accueil.

👀 Qu'observez-vous ?

Demande : une table pour + nombre + personnes, s'il vous plaît. Réponse : suivez-moi, je vous installe, avez-vous réservé ?

Formule / Règle : Au restaurant : une table pour + nombre, s'il vous plaît ; nous sommes + nombre ; la question avez-vous réservé ? ouvre l'accueil.

★ Pourquoi c'est important

C'est la première phrase échangée au restaurant : courte, polie, elle contient toutes les informations nécessaires.

💭 Pensez comme un francophone

Un francophone dit « une table pour deux » sans ajouter personnes.

🗣️ Note de prononciation

personnes se prononce /pɛʁ.sɔn/.

Banque d'exemples complémentaires
  • Forme affirmative : Nous voudrions une table pour quatre.
  • Forme interrogative : Vous avez une table pour deux ?
  • Forme négative : Il n'y a plus de table pour deux.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Une table à deux personnes.

✅ Correct : Une table pour deux personnes.

❌ Erreur : Nous avons trois.

✅ Correct : Nous sommes trois.
