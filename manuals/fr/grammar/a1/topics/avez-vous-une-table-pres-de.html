Grammaire Française A1

Avez-vous une table près de… ?

Demander une table à un endroit précis.

🎯 Objectif de communication : Vous savez demander une place particulière au restaurant.
Exemples en contexte
  • Exemple 1 : Avez-vous une table près de la fenêtre ? — Question avec près de.
  • Exemple 2 : Oui, une table pour deux près de la fenêtre. — Réponse avec reprise.
  • Exemple 3 : Non, elles sont toutes réservées. — Réponse négative.

👀 Qu'observez-vous ?

Question : avez-vous + nom + près de / à côté de / en terrasse ? Réponse : oui, une table + précision, non, elles sont toutes réservées.

Élément / Structure Rôle en français Exemple d'application
avez-vous + nom ? question avez-vous une table
près de / à côté de proximité près de la fenêtre
en terrasse emplacement une table en terrasse
être réservé indisponibilité elles sont réservées
pour + nombre nombre de personnes une table pour deux

Formule / Règle : Demander une place : avez-vous + nom + près de / en terrasse ? Réponse avec reprise (une table pour deux) ou refus poli (toutes réservées).

★ Pourquoi c'est important

Cette demande précise évite d'être placé à un endroit indésirable et montre que l'on connaît les usages.

💭 Pensez comme un francophone

Un francophone ajoute « si possible » pour adoucir : « près de la fenêtre, si possible ».

🗣️ Note de prononciation

près de se prononce /pʁɛ də/, terrasse /te.ʁas/.

Banque d'exemples complémentaires
  • Forme affirmative : Nous avons une table près de la fenêtre.
  • Forme interrogative : Avez-vous une table en terrasse ?
  • Forme négative : Il n'y a plus de table près de la fenêtre.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Avez-vous une table près la fenêtre ?

✅ Correct : Avez-vous une table près de la fenêtre ?

❌ Erreur : Elles sont tout réservées.

✅ Correct : Elles sont toutes réservées.
