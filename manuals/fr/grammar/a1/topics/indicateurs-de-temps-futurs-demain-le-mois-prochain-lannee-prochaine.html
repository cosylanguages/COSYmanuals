Grammaire Française A1

Les indicateurs de temps futurs

Demain, ce soir, la semaine prochaine, dans deux jours.

🎯 Objectif de communication : Vous savez situer une action dans l'avenir avec les bons marqueurs de temps.
Exemples en contexte
  • Exemple 1 : Demain, je vais partir. — demain se place en tête ou en fin de phrase.
  • Exemple 2 : La semaine prochaine, nous allons déménager. — prochain s'accorde : la semaine prochaine, le mois prochain.
  • Exemple 3 : Je pars dans deux jours. — dans + durée situe dans le futur.

👀 Qu'observez-vous ?

Les marqueurs futurs sont nombreux : demain, après-demain, ce soir, bientôt, la semaine prochaine, le mois prochain, l'année prochaine, dans + durée.

Élément / Structure Rôle en français Exemple d'application
demain / après-demain le jour suivant Demain, je pars.
ce soir / cet après-midi aujourd'hui, plus tard Ce soir, nous sortons.
la semaine / le mois / l'année prochaine période suivante l'année prochaine
dans + durée futur compté dans deux heures
bientôt / tout à l'heure futur proche à bientôt !

Formule / Règle : Indicateurs futurs : demain, après-demain, ce soir, bientôt, la semaine/le mois/l'année prochaine, dans + durée. Ils accompagnent le futur proche ou le futur simple.

★ Pourquoi c'est important

Sans indicateur de temps, le futur proche reste vague. Ces mots précisent quand, ce qui est presque toujours nécessaire dans un projet.

💭 Pensez comme un francophone

Un francophone dit « à la semaine prochaine » en partant, sans verbe : la formule suffit.

🗣️ Note de prononciation

prochain se prononce /pʁɔ.ʃɛ̃/, avec le in nasal. Féminin : prochaine /pʁɔ.ʃɛn/.

Banque d'exemples complémentaires
  • Forme affirmative : Nous allons nous voir la semaine prochaine.
  • Forme interrogative : Tu pars demain ?
  • Forme négative : Je ne travaille pas ce soir.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le semaine prochaine

✅ Correct : la semaine prochaine

❌ Erreur : dans trois jours passés

✅ Correct : il y a trois jours
