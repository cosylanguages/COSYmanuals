Grammaire Française A1

Combien coûte un billet pour… ?

Demander le prix d'un billet.

🎯 Objectif de communication : Vous savez demander un tarif de transport.
Exemples en contexte
  • Exemple 1 : Combien coûte un billet pour Lyon ? — Question avec coûter.
  • Exemple 2 : Un billet aller simple coûte vingt euros. — Réponse avec type de billet.
  • Exemple 3 : Il y a un tarif étudiant. — Réponse avec tarif réduit.

👀 Qu'observez-vous ?

Question : combien coûte + un billet pour + destination ? Réponse : coûter + prix, avec les types : aller simple, aller-retour, tarif étudiant.

Formule / Règle : Prix d'un billet : combien coûte + billet + pour + destination ? Réponse avec le type (aller simple, aller-retour) et le prix.

★ Pourquoi c'est important

Cette question combine le prix et la destination : elle suffit à préparer un achat de billet.

💭 Pensez comme un francophone

Un francophone demande « c'est combien pour Lyon ? ».

🗣️ Note de prononciation

billet se prononce /bi.jɛ/, coûte /kut/.

Banque d'exemples complémentaires
  • Forme affirmative : Un aller-retour pour Lyon coûte quarante euros.
  • Forme interrogative : Combien coûte un billet pour Paris ?
  • Forme négative : Il n'y a pas de tarif réduit.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Combien coûte un billet à Lyon ?

✅ Correct : Combien coûte un billet pour Lyon ?

❌ Erreur : Il coûte de vingt euros.

✅ Correct : Il coûte vingt euros.
