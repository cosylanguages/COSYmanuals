Grammaire Française A1

L'imparfait pour décrire

La maison était grande et claire.

🎯 Objectif de communication : Vous savez décrire une situation passée.
Exemples en contexte
  • Exemple 1 : La maison était grande et claire. — Description d'un lieu.
  • Exemple 2 : Il avait les cheveux longs. — Description d'une personne.
  • Exemple 3 : Il faisait froid ce jour-là. — Description du temps.

👀 Qu'observez-vous ?

L'imparfait décrit : un lieu (la maison était grande), une personne (il avait les cheveux longs), une ambiance (il faisait froid). Il ne raconte pas d'action.

Élément / Structure Rôle en français Exemple d'application
imparfait + adjectif description la maison était grande
imparfait + avoir description physique il avait les cheveux longs
imparfait + météo ambiance il faisait froid
imparfait + état situation j'étais fatigué
passé composé action je suis entré

Formule / Règle : Description au passé : imparfait + adjectif, avoir, état. L'imparfait ne fait pas avancer l'action, il la situe.

★ Pourquoi c'est important

La description d'un souvenir commence toujours par l'imparfait : c'est lui qui donne l'image avant l'événement.

💭 Pensez comme un francophone

Un francophone ouvre un souvenir par « c'était… ».

🗣️ Note de prononciation

était se prononce /e.tɛ/, avaient /a.vɛ/.

Banque d'exemples complémentaires
  • Forme affirmative : La ville était calme et les rues étaient vides.
  • Forme interrogative : Comment était la maison ?
  • Forme négative : Il n'était pas grand.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : La maison a été grande (description).

✅ Correct : La maison était grande.

❌ Erreur : Il a eu les cheveux longs (description).

✅ Correct : Il avait les cheveux longs.
