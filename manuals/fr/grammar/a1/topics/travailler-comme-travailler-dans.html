Grammaire Française A1

Travailler comme / travailler dans

Dire son métier et son lieu de travail.

🎯 Objectif de communication : Vous savez distinguer travailler comme + métier et travailler dans + lieu ou secteur.
Exemples en contexte
  • Exemple 1 : Je travaille comme professeur. — comme introduit le métier, sans article.
  • Exemple 2 : Je travaille dans une école. — dans introduit le lieu de travail.
  • Exemple 3 : Elle travaille dans la finance. — dans peut aussi introduire un secteur.

👀 Qu'observez-vous ?

comme + métier (sans article), dans + un/une/le/la + lieu ou secteur. On peut combiner les deux : je travaille comme infirmier dans un hôpital.

💡 Vérifiez votre compréhension (CCQ)

1. Dit-on « je travaille comme un professeur » ?
Après comme, le métier s'emploie sans article.
2. Quelle préposition pour le lieu ?
Le lieu se construit avec dans : dans une école, dans un bureau.
Élément / Structure Rôle en français Exemple d'application
travailler comme + métier sans article travailler comme médecin
travailler dans + lieu avec article travailler dans un hôpital
travailler dans + secteur domaine d'activité travailler dans le tourisme
travailler à + ville lieu géographique travailler à Paris
travailler chez + personne employeur travailler chez Renault

Formule / Règle : travailler comme + métier (sans article), travailler dans + lieu ou secteur (avec article), travailler à + ville, travailler chez + employeur.

★ Pourquoi c'est important

C'est la structure des présentations professionnelles : elle permet de dire à la fois le métier et le contexte.

💭 Pensez comme un francophone

Un francophone dit « je bosse dans l'informatique » à l'oral ; « je travaille » reste la forme neutre.

🗣️ Note de prononciation

comme se prononce /kɔm/. dans se prononce /dɑ̃/, nasal.

Banque d'exemples complémentaires
  • Forme affirmative : Il travaille comme ingénieur dans une entreprise allemande.
  • Forme interrogative : Vous travaillez comme quoi ?
  • Forme négative : Elle ne travaille pas dans ce service.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : Je travaille comme un professeur.

✅ Correct : Je travaille comme professeur.

❌ Erreur : Je travaille comme une école.

✅ Correct : Je travaille dans une école.
