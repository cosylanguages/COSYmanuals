Grammaire Française B2

Pronoms démonstratifs et possessifs complexes

Renforcer ou opposer sans répéter le nom.

🎯 Objectif de communication : Vous savez employer celui-ci, celui-là, ce dernier, le mien, le leur.
Exemples en contexte
  • Exemple 1 : Entre les deux rapports, celui-ci est plus prudent, celui-là plus rapide. — Opposition par démonstratifs.
  • Exemple 2 : Le premier argument est solide ; ce dernier emporte l'adhésion. — Reprise par ce dernier.
  • Exemple 3 : Votre analyse rejoint la nôtre sur l'essentiel. — Possessif pronominal.

👀 Qu'observez-vous ?

Démonstratifs : celui-ci / celui-là (proximité et distance, opposition), ce dernier / cette dernière (reprise du plus récent), ce qui / ce que (neutres). Possessifs : le mien, la tienne, les nôtres, le leur.

Élément / Structure Rôle en français Exemple d'application
celui-ci / celle-ci élément proche ou dernier cité celui-ci est plus prudent
celui-là / celle-là élément éloigné ou premier cité celui-là est plus rapide
ce dernier / cette dernière reprise du plus récent ce dernier emporte l'adhésion
ce qui / ce que neutre ce qui compte, c'est la méthode
le mien / la mienne possession, 1re personne votre analyse rejoint la mienne
le leur / la leur possession, 3e personne pluriel leur choix diffère du nôtre

Formule / Règle : Les démonstratifs pronominaux évitent la répétition et permettent l'opposition : celui-ci contre celui-là. Ce dernier renvoie à l'antécédent le plus proche, ce qui impose de vérifier qu'il n'y a pas d'ambiguïté.

★ Pourquoi c'est important

Dans un texte long, ce dernier est un piège : si deux noms précèdent, le lecteur peut se tromper. Mieux vaut répéter le nom ou écrire « le second ».

💭 Pensez comme un francophone

Le possessif pronominal s'accorde avec l'objet possédé, non avec le possesseur : la leur (analyse) pour plusieurs personnes.

🗣️ Note de prononciation

celui-ci /sə.lɥi.si/, la nôtre /la notʁ/.

Banque d'exemples complémentaires
  • Opposition : Des deux projets, celui-ci coûte moins, celui-là dure plus.
  • Reprise : La commission a rendu un avis ; ce dernier est réservé.
  • Possession : Leur conclusion diffère de la nôtre.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : ce dernier alors que deux noms le précèdent

✅ Correct : préférer le second ou répéter le nom

❌ Erreur : la notre

✅ Correct : la nôtre
