Reformuler pour rapprocher

Dire ce que les deux parties expriment.

🎯 Objectif de communication : Vous savez reformuler les positions pour rapprocher.
Exemples en contexte
  • Exemple 1 : Ce que les deux parties expriment, c'est le besoin de visibilité. — Reformulation commune.
  • Exemple 2 : Cherchons le terrain d'entente : le calendrier, non le principe. — Recherche.
  • Exemple 3 : Si je résume : vous contestez la méthode, non l'objectif. — Vérification.

Formule / Règle : Reformuler pour rapprocher consiste à dégager ce qui est commun sans effacer les positions : « ce que les deux parties expriment, c'est le besoin de visibilité » laisse intactes les divergences tout en créant un point d'appui.

★ Pourquoi c'est important

Cherchons le terrain d'entente est la formule du déplacement : elle sort la discussion du principe, où le désaccord est irréductible, pour la porter sur le calendrier, où il est négociable. C'est la manœuvre la plus utile en médiation.

💭 Pensez comme un francophone

Si je résume vaut vérification, non conclusion : il permet de faire confirmer la reformulation avant de l'utiliser. Une reformulation non vérifiée est une interprétation, et l'autre la corrige en public.

🗣️ Note de prononciation

la reformulation /la ʁə.fɔʁ.my.la.sjɔ̃/, l'entente /l‿ɑ̃.tɑ̃t/.

Banque d'exemples complémentaires
  • Commun : Ce que les deux parties expriment, c'est le besoin de visibilité sur les délais.
  • Déplacement : Cherchons un terrain d'entente sur le calendrier ; le principe reste débattu.
  • Vérification : Si je résume : la méthode est contestée, l'objectif ne l'est pas.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : vous dites la même chose en fait (reformulation)

✅ Correct : ce que les deux parties expriment, c'est le besoin de visibilité

❌ Erreur : donc vous êtes d'accord sur le calendrier (reformulation)

✅ Correct : sur le calendrier, pouvez-vous vous accorder ?
