Grammaire Française B2

L'infinitif passé

Marquer l'antériorité dans une proposition infinitive.

🎯 Objectif de communication : Vous savez employer l'infinitif passé pour une action antérieure.
Exemples en contexte
  • Exemple 1 : Après avoir relu le texte, la commission a rendu son avis. — Antériorité.
  • Exemple 2 : Il regrette d'avoir signé si vite. — Regret d'une action passée.
  • Exemple 3 : Sans avoir vérifié les sources, il a publié l'article. — Absence d'action antérieure.

👀 Qu'observez-vous ?

Infinitif passé = avoir ou être à l'infinitif + participe passé. Il marque une action achevée avant celle du verbe principal. Après pour, après, sans, au lieu de, il remplace l'infinitif présent quand l'action est antérieure.

Élément / Structure Rôle en français Exemple d'application
après avoir + participe antériorité après avoir relu le texte
après être + participe antériorité avec être après être arrivés en retard
regretter d'avoir + participe regret il regrette d'avoir signé
sans avoir + participe absence d'action sans avoir vérifié les sources
au lieu d'avoir + participe substitution au lieu d'avoir consulté, il a tranché
pour avoir + participe cause il a été sanctionné pour avoir menti

Formule / Règle : L'infinitif passé situe une action avant celle du verbe principal, là où l'infinitif présent la situe en même temps. La distinction est nette après après, sans et pour.

★ Pourquoi c'est important

Pour avoir + participe exprime la cause : « sanctionné pour avoir menti ». C'est une tournure fréquente dans les récits de faute.

💭 Pensez comme un francophone

L'accord suit la règle du participe passé : avec être, accord avec le sujet ; avec avoir, accord avec un COD antéposé.

🗣️ Note de prononciation

après avoir relu /a.pʁɛ.z‿a.vwaʁ ʁə.ly/.

Banque d'exemples complémentaires
  • Antériorité : Après avoir examiné les pièces, le juge a statué.
  • Regret : Elle regrette d'avoir parlé trop vite.
  • Cause : Il a été révoqué pour avoir divulgué le document.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : après avoir relu de le texte

✅ Correct : après avoir relu le texte

❌ Erreur : après être arrivé en retard, ils ont été reçus (sujet pluriel)

✅ Correct : après être arrivés en retard
