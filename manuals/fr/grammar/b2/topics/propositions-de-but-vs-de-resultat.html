Grammaire Française B2

But ou résultat

Distinguer l'intention de l'effet.

🎯 Objectif de communication : Vous savez distinguer une proposition de but d'une proposition de résultat.
Exemples en contexte
  • Exemple 1 : Nous avons réuni les équipes afin de fixer un calendrier. — But.
  • Exemple 2 : Nous avons réuni les équipes, si bien qu'un calendrier a été fixé. — Résultat.
  • Exemple 3 : La réunion a permis de fixer un calendrier. — Résultat constaté.

👀 Qu'observez-vous ?

But : afin de, pour que + subjonctif, de manière à, en vue de, dans le but de. Résultat : si bien que, de sorte que, au point que, ce qui fait que, d'où.

Élément / Structure Rôle en français Exemple d'application
afin de + infinitif but fixer un calendrier
pour que + subjonctif but avec sujet différent pour que le calendrier soit fixé
de manière à but de manière à tenir la date
si bien que + indicatif résultat un calendrier a été fixé
de sorte que résultat ou but de sorte qu'un accord est intervenu
d'où résultat nominal d'où un retard de deux mois

Formule / Règle : Le but est visé, le résultat est constaté : c'est la différence de mode qui les sépare (pour que + subjonctif, si bien que + indicatif) et la différence de temps de l'action. Confondre les deux produit des rapports qui présentent une intention comme un effet.

★ Pourquoi c'est important

De sorte que est ambigu : suivi de l'indicatif il exprime un résultat, suivi du subjonctif un but. C'est le seul articulateur de la série qui fonctionne dans les deux sens, ce qui en fait une source d'ambiguïté rédactionnelle.

💭 Pensez comme un francophone

D'où est le plus économique pour un résultat nominal : il remplace « ce qui a produit » en un mot. Il convient aux analyses où les causes et les effets s'enchaînent.

🗣️ Note de prononciation

afin de /a.fɛ̃ də/, de sorte que /də sɔʁ.tə kə/.

Banque d'exemples complémentaires
  • But : Nous avons avancé la séance afin de disposer du quorum.
  • Résultat : Nous avons avancé la séance, si bien que le quorum était atteint.
  • Nominal : La séance a été avancée, d'où un quorum atteint.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : nous avons réuni les équipes afin qu'un calendrier a été fixé (but et fait réalisé)

✅ Correct : nous avons réuni les équipes afin de fixer un calendrier, ce qui a été fait

❌ Erreur : nous avons avancé la séance afin de le quorum soit atteint

✅ Correct : nous avons avancé la séance afin que le quorum soit atteint
