Grammaire Française B2

Les tournures passives sans complément d'agent

Décrire un état ou une procédure sans dire qui agit.

🎯 Objectif de communication : Vous savez employer le passif sans agent et distinguer passif d'action et passif d'état.
Exemples en contexte
  • Exemple 1 : Le dossier est examiné depuis mars. — Passif d'action, agent inutile.
  • Exemple 2 : La porte est fermée à clé. — Passif d'état : description.
  • Exemple 3 : Les candidatures seront reçues jusqu'au 15. — Passif de procédure.

👀 Qu'observez-vous ?

Passif sans agent : l'agent est inconnu, évident ou sans intérêt. Passif d'action (événement) contre passif d'état (résultat) : la décision a été prise / la décision est prise.

💡 Vérifiez votre compréhension (CCQ)

Score : 0 / 2
1. Quelle différence entre a été fermé et est fermé ?
La porte a été fermée (action) / la porte est fermée (état).
2. Quand omet-on l'agent ?
Les candidatures seront reçues : par qui importe peu.
Élément / Structure Rôle en français Exemple d'application
a été examiné passif d'action, passé composé le dossier a été examiné hier
est examiné passif d'état ou d'habitude le dossier est examiné depuis mars
sera reçu passif de procédure les candidatures seront reçues jusqu'au 15
est fermé à clé passif d'état descriptif la porte est fermée à clé
se voit attribuer passif pronominal le prix se voit attribuer chaque année
il est procédé à passif impersonnel il est procédé au tirage au sort

Formule / Règle : Le passif sans agent sert quand l'agent n'apporte rien : procédures, constats, descriptions. Le choix du temps distingue l'événement (a été) de l'état (est), distinction que le français marque plus nettement que l'anglais.

★ Pourquoi c'est important

Dans un rapport, « le dossier est examiné » peut signifier « en ce moment » ou « régulièrement » : le contexte tranche, et le circonstant aide (depuis mars, chaque mois).

💭 Pensez comme un francophone

Le passif d'état se confond avec l'adjectif : la porte est fermée est aussi une description. L'ajout d'un complément (à clé, depuis hier) lève l'ambiguïté.

🗣️ Note de prononciation

les candidatures seront reçues /le kɑ̃.di.da.tyʁ sə.ʁɔ̃ ʁə.sy/.

Banque d'exemples complémentaires
  • Événement : Le texte a été adopté mardi.
  • État : Le texte est adopté depuis mardi.
  • Procédure : Les dossiers sont déposés au secrétariat.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le dossier est examiné hier

✅ Correct : le dossier a été examiné hier

❌ Erreur : la décision est prise par hier

✅ Correct : la décision a été prise hier
