Grammaire Française B2

Le conditionnel de l'information non confirmée

Rapporter un fait sans en garantir l'exactitude.

🎯 Objectif de communication : Vous savez employer le conditionnel de presse pour une information non vérifiée.
Exemples en contexte
  • Exemple 1 : Le ministre aurait démissionné selon deux sources concordantes. — Information non confirmée.
  • Exemple 2 : Une réunion se serait tenue hier soir. — Fait rapporté, non attesté.
  • Exemple 3 : Le texte, qui serait déjà rédigé, serait examiné lundi. — Deux conditionnels dans la même phrase.

👀 Qu'observez-vous ?

Conditionnel de presse : le fait est rapporté sans être confirmé par le journal. Il s'accompagne d'une mention de source (selon, d'après) ou de l'indication que la vérification est en cours.

Formule / Règle : Le conditionnel de presse signale que le journal rapporte sans garantir. Il ne marque ni le futur ni l'hypothèse : c'est un conditionnel de citation, équivalent à « selon nos informations ».

★ Pourquoi c'est important

Un fait confirmé se met à l'indicatif : le ministre a démissionné. Passer du conditionnel à l'indicatif dans une même dépêche signale que la vérification a abouti.

💭 Pensez comme un francophone

À l'oral, ce conditionnel s'emploie pour les rumeurs : « il aurait dit que… ». Il sert alors à rapporter sans s'engager.

🗣️ Note de prononciation

aurait démissionné /o.ʁɛ de.mi.sjɔ.ne/.

Banque d'exemples complémentaires
  • Non confirmé : Le rapport serait prêt, selon nos informations.
  • Confirmé : Le rapport est prêt, a confirmé le ministère.
  • Réserve : L'information n'a pas pu être confirmée dans l'immédiat.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le ministre a démissionné selon deux sources (non confirmé)

✅ Correct : le ministre aurait démissionné

❌ Erreur : il aurait démissionné de

✅ Correct : il aurait démissionné
