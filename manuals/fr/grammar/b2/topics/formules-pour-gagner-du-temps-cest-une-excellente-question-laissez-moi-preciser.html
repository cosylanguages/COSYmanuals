Gagner du temps

Répondre sans répondre tout de suite.

🎯 Objectif de communication : Vous savez gagner du temps sans esquiver.
Exemples en contexte
  • Exemple 1 : C'est une excellente question ; laissez-moi préciser un point avant d'y revenir. — Report motivé.
  • Exemple 2 : Je n'ai pas le chiffre exact ; je vous le fais passer cet après-midi. — Report honnête.
  • Exemple 3 : Cette question en suppose une autre : de quel périmètre parle-t-on ? — Décomposition.

Formule / Règle : Gagner du temps n'est légitime que si le report est motivé et daté : « laissez-moi préciser un point » annonce une réponse prochaine, « je vous le fais passer cet après-midi » en fixe l'échéance. Un report sans date est une esquive, et l'auditoire le sait.

★ Pourquoi c'est important

L'aveu d'ignorance (je n'ai pas le chiffre exact) est la meilleure façon de gagner du temps : il est crédible, il évite une erreur, et il engage à revenir. Inventer un chiffre est la seule faute vraiment grave.

💭 Pensez comme un francophone

La décomposition (cette question en suppose une autre) est la technique la plus solide : elle montre que la question mal posée demande une précision, ce qui est souvent vrai et permet de reprendre l'initiative.

🗣️ Note de prononciation

valoriser /va.lɔ.ʁi.ze/, la décomposition /la de.kɔ̃.po.zi.sjɔ̃/.

Banque d'exemples complémentaires
  • Valorisation : C'est la bonne question ; je vais y venir précisément.
  • Aveu : Je n'ai pas le chiffre sous les yeux ; je le transmets ce soir.
  • Décomposition : Avant de répondre, il faut s'entendre sur le périmètre.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : excellente question, je ne sais pas (report non motivé)

✅ Correct : c'est une excellente question ; je n'ai pas le chiffre exact et je vous le fais passer cet après-midi

❌ Erreur : cette question en suppose une autre, et d'ailleurs la question est mal posée (décomposition insistante)

✅ Correct : cette question en suppose une autre : de quel périmètre parle-t-on ?
