Grammaire Française B2

Le subjonctif de but

Fixer un objectif quand les sujets diffèrent.

🎯 Objectif de communication : Vous savez employer afin que, pour que et de façon que avec le subjonctif.
Exemples en contexte
  • Exemple 1 : Le texte est publié afin que chacun puisse le consulter. — But avec deux sujets.
  • Exemple 2 : Nous parlons lentement pour que tous comprennent. — But immédiat.
  • Exemple 3 : La salle a été réaménagée de façon que la circulation soit fluide. — But de conception.

👀 Qu'observez-vous ?

But : afin que, pour que, de façon que, de manière que + subjonctif ; afin de, pour, de façon à + infinitif (même sujet). De sorte que + subjonctif marque le but, + indicatif le résultat constaté.

Élément / Structure Rôle en français Exemple d'application
afin que + subjonctif but formel afin que chacun puisse consulter
pour que + subjonctif but courant pour que tous comprennent
de façon que + subjonctif but de conception de façon que la circulation soit fluide
de sorte que + subjonctif but de sorte que nul ne soit exclu
de sorte que + indicatif résultat constaté de sorte que la circulation est fluide
afin de + infinitif but, même sujet afin de réduire les délais

Formule / Règle : Le choix entre afin que et afin de dépend uniquement de l'identité des sujets. De sorte que est le cas le plus subtil : subjonctif pour le but visé, indicatif pour le résultat observé.

★ Pourquoi c'est important

Dans un texte de projet, le but au subjonctif est la norme : il énonce ce que la mesure doit produire, sans affirmer qu'elle le produit.

💭 Pensez comme un francophone

À l'oral, « pour que » domine ; « afin que » appartient à l'écrit soigné, « de façon que » au style technique.

🗣️ Note de prononciation

afin que /a.fɛ̃ kə/, de sorte que /də sɔʁt kə/.

Banque d'exemples complémentaires
  • But, sujets différents : Un délai est ouvert afin que les recours soient exercés.
  • But, même sujet : Le comité se réunit afin d'examiner le dossier.
  • Résultat constaté : Les salles ont été réaménagées, de sorte que la circulation est fluide.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : afin que chacun peut consulter

✅ Correct : afin que chacun puisse consulter

❌ Erreur : afin de que tous comprennent

✅ Correct : afin que tous comprennent
