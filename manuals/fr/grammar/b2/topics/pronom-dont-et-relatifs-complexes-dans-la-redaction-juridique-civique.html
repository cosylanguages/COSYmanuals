Grammaire Française B2

Le pronom dont et les relatifs complexes

Enchaîner les définitions d'un texte normatif.

🎯 Objectif de communication : Vous savez employer dont, auquel, duquel et leurs composés.
Exemples en contexte
  • Exemple 1 : Le droit dont jouit chaque citoyen est garanti. — Dont = de + antécédent.
  • Exemple 2 : La loi à laquelle il se réfère date de 1905. — À laquelle = à + antécédent féminin.
  • Exemple 3 : Le service auprès duquel la demande est déposée. — Duquel après auprès de.

👀 Qu'observez-vous ?

Relatifs complexes : dont (de qui, duquel), auquel / à laquelle / auxquels, duquel / de laquelle, sur lequel, auprès duquel, pour lequel. Dont ne se combine pas avec une autre préposition : on dit « le service auprès duquel », non « auprès dont ».

Élément / Structure Rôle en français Exemple d'application
dont de + antécédent le droit dont jouit le citoyen
auquel / à laquelle à + antécédent la loi à laquelle il se réfère
duquel / de laquelle de + antécédent (formes longues) le service duquel dépend le dossier
auprès duquel préposition + duquel le service auprès duquel on dépose
sur lequel préposition + lequel le texte sur lequel repose l'accord
ce dont neutre ce dont il est question

Formule / Règle : Les relatifs complexes évitent les répétitions dans un texte à forte densité nominale. La règle à retenir : dont vaut à lui seul de + antécédent, et toute autre préposition impose duquel ou auquel.

★ Pourquoi c'est important

Dans un texte juridique, la précision du relatif est essentielle : un antécédent mal rattaché change l'obligation. On préfère parfois répéter le nom plutôt que risquer l'ambiguïté.

💭 Pensez comme un francophone

Dont est très fréquent à l'écrit et souvent évité à l'oral, où l'on préfère deux phrases : « c'est le droit de ce citoyen ».

🗣️ Note de prononciation

le droit dont jouit /lə dʁwa dɔ̃ ʒwi/.

Banque d'exemples complémentaires
  • Dont : La mesure dont bénéficient les locataires entre en vigueur.
  • À laquelle : La règle à laquelle renvoie le contrat est ancienne.
  • Auprès duquel : L'organisme auprès duquel la demande est instruite.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le service auprès dont on dépose

✅ Correct : le service auprès duquel on dépose

❌ Erreur : la loi dont il se réfère à

✅ Correct : la loi à laquelle il se réfère
