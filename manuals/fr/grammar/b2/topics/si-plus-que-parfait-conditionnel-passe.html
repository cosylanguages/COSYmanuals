Grammaire Française B2

Si + plus-que-parfait → conditionnel passé

Énoncer ce qui aurait eu lieu si la condition avait été remplie.

🎯 Objectif de communication : Vous savez construire l'hypothèse irréelle du passé.
Exemples en contexte
  • Exemple 1 : Si le rapport avait été publié, le débat aurait eu lieu. — Condition non réalisée.
  • Exemple 2 : Nous aurions évité la crise si nous avions écouté les alertes. — Conséquence d'abord.
  • Exemple 3 : Si elle avait su, elle n'aurait pas signé. — Négation dans chaque membre.

👀 Qu'observez-vous ?

Système : si + plus-que-parfait (avais fait, étais parti) → conditionnel passé (aurais fait, serais parti). Les deux membres peuvent être inversés. Le système mixte est possible : si + plus-que-parfait → conditionnel présent (si j'avais su, je serais plus prudent).

Formule / Règle : Le système du troisième degré se reconnaît à l'accord des temps : plus-que-parfait dans la subordonnée, conditionnel passé dans la principale. Inverser les deux (« si le rapport aurait été publié ») est la faute la plus fréquente et la plus visible à l'examen.

★ Pourquoi c'est important

Le système mixte permet une conséquence encore actuelle : « si j'avais su, je serais plus prudent » — la condition est passée, la conséquence présente. C'est souvent ce que l'on veut dire en analyse d'erreur.

💭 Pensez comme un francophone

Sans + nom remplace économique­ment la subordonnée : « sans son alerte, l'incendie se propageait ».

🗣️ Note de prononciation

si j'avais su /si ʒa.vɛ sy/, j'aurais agi /ʒo.ʁɛ z‿a.ʒi/.

Banque d'exemples complémentaires
  • Irréel : Si la consigne avait été écrite, l'erreur aurait été évitée.
  • Mixte : S'il avait été prévenu, il serait aujourd'hui présent.
  • Sans + nom : Sans la réforme, les délais seraient restés identiques.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : si le rapport aurait été publié

✅ Correct : si le rapport avait été publié

❌ Erreur : j'aurais agi si j'aurais su

✅ Correct : j'aurais agi si j'avais su
