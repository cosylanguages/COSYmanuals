Grammaire Française B2

Participe présent ou adjectif

Distinguer ce qui agit de ce qui décrit.

🎯 Objectif de communication : Vous savez distinguer participe présent et adjectif verbal.
Exemples en contexte
  • Exemple 1 : Une décision concernant les équipes a été prise. — Participe présent.
  • Exemple 2 : Les équipes concernées seront informées. — Adjectif verbal.
  • Exemple 3 : Une réunion réunissant six services s'est tenue. — Participe présent.

👀 Qu'observez-vous ?

Participe présent : invariable, exprime une action (concernant, réunissant, portant). Adjectif verbal : variable, exprime une qualité (concerné, convaincant, fatiguant / fatigant).

Élément / Structure Rôle en français Exemple d'application
participe présent invariable, action une décision concernant les équipes
adjectif verbal variable, qualité les équipes concernées
participe présent composé antériorité ayant examiné le dossier
gérondif simultanéité en examinant le dossier
adjectif verbal en -ant accord des arguments convaincants
double forme sens distinct fatigant (action) / fatigant (qualité)

Formule / Règle : La distinction est mécanique : le participe présent exprime une action et reste invariable ; l'adjectif verbal exprime une qualité et s'accorde. « Une décision concernant les équipes » (action) contre « les équipes concernées » (qualité).

★ Pourquoi c'est important

Certains mots ont deux formes avec deux sens : fatigant (adjectif : pénible) et fatiguant (participe : qui fatigue). L'orthographe distingue donc le sens, ce qui est l'un des rares cas où une lettre porte une distinction sémantique.

💭 Pensez comme un francophone

Le gérondif (en examinant) exprime la simultanéité ou la manière, ce qui le distingue du participe présent (qui examinait) : le premier est adverbial, le second est adjectival.

🗣️ Note de prononciation

le participe /lə paʁ.ti.sip/, le gérondif /le ʒe.ʁɔ̃.dif/.

Banque d'exemples complémentaires
  • Action : Le texte portant sur les comptes a été voté.
  • Qualité : Les textes portants sont rares — les textes portant une réserve, nombreux.
  • Simultanéité : En examinant le dossier, le comité a relevé deux anomalies.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : les équipes concernant seront informées

✅ Correct : les équipes concernées seront informées

❌ Erreur : une décision concernée les équipes

✅ Correct : une décision concernant les équipes
