Le passif à valeur d'état

Décrire une situation installée plutôt qu'un événement.

🎯 Objectif de communication : Vous savez distinguer le passif d'état du passif d'action et l'employer à propos.
Exemples en contexte
  • Exemple 1 : Le quartier est enclavé par deux voies rapides. — État durable.
  • Exemple 2 : La zone est classée depuis 1998. — État juridique daté.
  • Exemple 3 : Les sols sont pollués aux métaux lourds. — État constaté.

👀 Qu'observez-vous ?

Passif d'état : être + participe passé, avec un complément qui décrit la cause (par, de, aux). Il équivaut souvent à un adjectif et ne se met pas au passif composé. Distinct du passif d'action (a été classé = on l'a classé).

Élément / Structure Rôle en français Exemple d'application
être + participe (état) état durable le quartier est enclavé
être classé depuis état juridique daté la zone est classée depuis 1998
être pollué aux état constaté les sols sont pollués aux métaux lourds
être bordé de description le terrain est bordé de haies
se trouver + participe état situé le site se trouve enclavé entre deux voies
a été + participe (action) événement la zone a été classée en 1998

Formule / Règle : Le français distingue l'état (la zone est classée) de l'événement (la zone a été classée). La description d'un territoire emploie l'état, le récit d'une politique l'action. Confondre les deux fait croire qu'une mesure vient d'être prise.

★ Pourquoi c'est important

Dans un diagnostic territorial, le passif d'état est la forme naturelle : « le quartier est enclavé », « les sols sont pollués ». Il décrit ce qui pèse sur les habitants, non ce que l'administration a fait.

💭 Pensez comme un francophone

Attention au complément : pollué aux métaux lourds, bordé de haies, enclavé par deux voies. La préposition dépend du participe.

🗣️ Note de prononciation

est enclavé /ɛ.t‿ɑ̃.kla.ve/, est classée /ɛ kla.se/.

Banque d'exemples complémentaires
  • État : Le centre ancien est dégradé par l'humidité.
  • État juridique : Le site est inscrit à l'inventaire depuis 2003.
  • Événement : Le site a été inscrit à l'inventaire en 2003.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le quartier a été enclavé par deux voies (état durable)

✅ Correct : le quartier est enclavé par deux voies

❌ Erreur : les sols sont pollués de métaux lourds

✅ Correct : les sols sont pollués aux métaux lourds
