Les formes passives et pronominales de responsabilité

Attribuer ou éviter d'attribuer la responsabilité d'un fait.

🎯 Objectif de communication : Vous savez choisir entre passif, pronominal et tournure active selon la responsabilité visée.
Exemples en contexte
  • Exemple 1 : Une erreur a été commise dans le calcul. — Passif : l'agent disparaît.
  • Exemple 2 : Le service s'est trompé sur le barème. — Pronominal : responsabilité assumée.
  • Exemple 3 : La direction a validé le barème erroné. — Actif : l'agent est nommé.

👀 Qu'observez-vous ?

Responsabilité : passif sans agent (une erreur a été commise) efface le responsable ; pronominal (s'est trompé, s'engage à) situe l'action dans le sujet ; actif nomme l'agent. Les verbes pronominaux de responsabilité : s'engager à, se tromper, s'excuser de, se porter garant.

Élément / Structure Rôle en français Exemple d'application
passif sans agent responsabilité effacée une erreur a été commise
passif avec agent responsabilité attribuée le barème a été validé par la direction
pronominal de responsabilité engagement du sujet le service s'engage à corriger
pronominal d'erreur faute assumée le service s'est trompé
tournure impersonnelle responsabilité diffuse il a été procédé à une vérification
actif responsabilité nommée la direction a validé le barème

Formule / Règle : Le choix de la forme est un choix de responsabilité : le passif sans agent dilue, le pronominal engage, l'actif désigne. Un rapport qui écrit systématiquement au passif sans agent devient un texte où personne n'a jamais rien fait.

★ Pourquoi c'est important

Dans une réponse à un usager, « une erreur a été commise » protège l'agent mais irrite ; « nous nous sommes trompés » assume et apaise. La grammaire est ici une question de relation.

💭 Pensez comme un francophone

Les verbes pronominaux de responsabilité se construisent avec à ou de : s'engager à, s'excuser de, se porter garant de.

🗣️ Note de prononciation

une erreur a été commise /yn e.ʁœʁ a e.te kɔ.miz/.

Banque d'exemples complémentaires
  • Effacement : Des retards ont été constatés dans le traitement.
  • Engagement : Le service s'engage à traiter les dossiers sous huit jours.
  • Attribution : Le prestataire a livré les pièces hors délai.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le service s'est trompé de le barème

✅ Correct : le service s'est trompé sur le barème

❌ Erreur : nous nous excusons de le retard

✅ Correct : nous nous excusons du retard
