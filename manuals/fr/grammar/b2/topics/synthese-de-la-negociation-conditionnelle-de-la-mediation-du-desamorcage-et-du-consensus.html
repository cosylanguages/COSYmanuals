Grammaire Française B2

Synthèse : négociation, médiation, consensus

Réunir les quatre outils du conflit réglé.

🎯 Objectif de communication : Vous savez conduire une négociation de bout en bout.
Exemples en contexte
  • Exemple 1 : Je comprends votre agacement ; pourvu que le calendrier soit révisé, nous serions prêts à revoir le volume. — Désamorçage puis échange.
  • Exemple 2 : Cherchons le terrain d'entente : le calendrier, non le principe. — Médiation.
  • Exemple 3 : Sur le diagnostic, vous convergez ; sur la méthode, non. — Consensus partiel.

👀 Qu'observez-vous ?

Quatre outils : désamorcer (je comprends votre agacement), échanger (pourvu que X, nous serions prêts à Y), médiatiser (cherchons le terrain d'entente), enregistrer le consensus (ce point est acquis).

Formule / Règle : Une négociation se conduit dans un ordre : désamorcer l'émotion, puis échanger (une concession contre une autre), puis médiatiser si le désaccord persiste, puis enregistrer. Inverser l'ordre — échanger avant d'avoir reconnu l'émotion — produit des concessions que l'autre ne voit pas.

★ Pourquoi c'est important

Le consensus partiel est l'outil le plus utile en pratique : il isole ce sur quoi les parties s'accordent (le diagnostic) de ce sur quoi elles divergent (la méthode). C'est ce qui permet d'avancer sans résoudre le fond.

💭 Pensez comme un francophone

Enregistrer est ce qui manque le plus souvent : une négociation non consignée se défait, car chacun repart avec sa lecture. La trace n'est pas une formalité administrative, elle est ce qui rend l'accord réel.

🗣️ Note de prononciation

désamorcer /de.za.mɔʁ.se/, médiatiser /me.dja.ti.ze/.

Banque d'exemples complémentaires
  • Ordre : Je comprends votre agacement ; cherchons un terrain d'entente sur le calendrier.
  • Échange : Pourvu que la livraison soit garantie, nous acceptons le prix.
  • Trace : Trois points convenus ; le relevé sera visé.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : pourvu que vous acceptez, nous serions prêts (négociation)

✅ Correct : pourvu que vous acceptiez, nous serions prêts

❌ Erreur : calmez-vous et cherchons un terrain d'entente (médiation)

✅ Correct : je comprends votre agacement ; cherchons un terrain d'entente
