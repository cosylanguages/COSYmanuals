Grammaire Française B2

Le subjonctif dans la relative après un superlatif

Nuancer un jugement absolu.

🎯 Objectif de communication : Vous savez employer le subjonctif après un superlatif ou un indéfini.
Exemples en contexte
  • Exemple 1 : C'est le plus beau livre que j'aie lu. — Superlatif + subjonctif.
  • Exemple 2 : Le seul témoignage qui ait été conservé date de 1945. — Restriction + subjonctif.
  • Exemple 3 : Je cherche un exemple qui illustre ce point. — Antécédent indéfini.

👀 Qu'observez-vous ?

Subjonctif dans la relative après : un superlatif (le plus, le moins, le meilleur), le seul, le premier, le dernier, un indéfini (un, aucun, rien), une négation. L'indicatif revient quand le fait est constaté.

Élément / Structure Rôle en français Exemple d'application
le plus… que + subjonctif superlatif le plus beau livre que j'aie lu
le seul… qui + subjonctif restriction le seul témoignage qui ait été conservé
un… qui + subjonctif antécédent indéfini un exemple qui illustre ce point
aucun… qui + subjonctif négation aucun document qui contredise cette thèse
le premier… qui + subjonctif priorité le premier qui ait signalé le risque
le seul… qui + indicatif fait constaté le seul qui est arrivé à l'heure

Formule / Règle : Le subjonctif apparaît quand la relative ne décrit pas un fait constaté mais une propriété visée ou un jugement subjectif. Après un superlatif, le locuteur évalue : le mode marque cette subjectivité.

★ Pourquoi c'est important

L'indicatif reste possible quand le fait est établi et vérifiable : c'est le seul qui a répondu (on l'a constaté). Le subjonctif insiste sur le caractère unique du cas, non sur le fait.

💭 Pensez comme un francophone

À l'oral, l'indicatif gagne du terrain après le superlatif ; à l'écrit soutenu et aux examens, le subjonctif est attendu.

🗣️ Note de prononciation

le plus beau livre que j'aie lu /lə ply bo livʁ kə ʒɛ ly/.

Banque d'exemples complémentaires
  • Superlatif : C'est la mesure la plus efficace qu'on ait adoptée.
  • Restriction : Le seul argument qui tienne est celui du coût.
  • Indéfini : Nous cherchons un candidat qui connaisse le dossier.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le plus beau livre que j'ai lu

✅ Correct : le plus beau livre que j'aie lu

❌ Erreur : le seul qui a été conservé (sans nuance)

✅ Correct : le seul qui ait été conservé
