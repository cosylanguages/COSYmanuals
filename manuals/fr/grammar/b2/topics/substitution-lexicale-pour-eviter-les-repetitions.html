Grammaire Française B2

Éviter les répétitions

Reprendre sans répéter.

🎯 Objectif de communication : Vous savez éviter une répétition par substitution.
Exemples en contexte
  • Exemple 1 : Le rapport a été transmis ; ce document reste confidentiel. — Substitution par hyperonyme.
  • Exemple 2 : La mesure a été adoptée ; cette décision ne fait pas l'unanimité. — Substitution par conséquence.
  • Exemple 3 : Le comité s'est réuni ; l'instance a rendu son avis. — Substitution par synonyme.

👀 Qu'observez-vous ?

Substitution : hyperonyme (le document, le texte), synonyme (l'instance, le comité), métonymie (la salle, le service), pronom, nominalisation (cette décision), reprise par le contenu.

Élément / Structure Rôle en français Exemple d'application
hyperonyme terme plus général le document, le texte
synonyme terme équivalent l'instance pour le comité
métonymie contenant ou institution la salle, le service
pronom reprise grammaticale il, elle, celui-ci
nominalisation reprise d'une action cette décision, cette adoption
reprise par le contenu idée reprise la mesure → cette décision

Formule / Règle : La substitution évite la répétition sans perdre la référence : l'hyperonyme (le document) est le plus sûr, le synonyme (l'instance) le plus élégant, la métonymie (la salle) le plus vivant. Chacun a son registre.

★ Pourquoi c'est important

La reprise par le contenu est la plus subtile : elle reprend l'action par son résultat (la mesure a été adoptée → cette décision). Elle prouve que l'on a compris, non seulement répété.

💭 Pensez comme un francophone

L'excès de substitution nuit : si chaque mention du rapport est désignée autrement (le document, le texte, ce dernier, l'écrit), le lecteur perd la référence. La règle est de varier sans multiplier.

🗣️ Note de prononciation

l'hyperonyme /l‿i.pe.ʁɔ.nim/, la métonymie /la me.tɔ.ni.mi/.

Banque d'exemples complémentaires
  • Hyperonyme : La note a été diffusée ; ce document ne vaut pas validation.
  • Contenu : Le comité a tranché ; cette décision sera publiée.
  • Métonymie : Le service a répondu ; la maison reste prudente.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le rapport a été transmis, le rapport reste confidentiel, le rapport sera archivé (répétition)

✅ Correct : le rapport a été transmis ; ce document reste confidentiel et sera archivé

❌ Erreur : le comité s'est réuni, le comité a rendu son avis, le comité se réunira (répétition)

✅ Correct : le comité s'est réuni ; l'instance a rendu son avis
