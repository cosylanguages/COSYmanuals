Les participiales en présentation de recherche

Exposer une méthode en phrases condensées.

🎯 Objectif de communication : Vous savez présenter une méthode par participiales.
Exemples en contexte
  • Exemple 1 : Les données ayant été anonymisées, l'analyse a pu être conduite. — Antériorité passive.
  • Exemple 2 : Partant d'un corpus de 400 entretiens, nous avons codé trois catégories. — Point de départ.
  • Exemple 3 : Une fois les entretiens codés, deux profils se sont dégagés. — Résultat.

👀 Qu'observez-vous ?

Recherche : les données ayant été + participe, partant de + nom, une fois + participe, étant donné, à partir de, les entretiens codés, eu égard à la taille de l'échantillon.

eu égard à + nom limite eu égard à la taille de l'échantillon

Formule / Règle : Dans une présentation de recherche, la participiale décrit une étape sans en faire une phrase : elle permet d'enchaîner méthode et résultat, ce qui est la structure attendue d'un exposé scientifique.

★ Pourquoi c'est important

Partant de marque le point de départ méthodologique ; à partir de marque la base matérielle. La nuance est celle du raisonnement contre le matériau.

💭 Pensez comme un francophone

Eu égard à la taille de l'échantillon est la formule de la limite : elle signale que la conclusion est bornée par les données, ce qui est une exigence de la présentation savante.

🗣️ Note de prononciation

partant de /paʁ.tɑ̃ də/, eu égard à /y e.ɡaʁ a/.

Banque d'exemples complémentaires

  • Base : À partir des données de 2022, nous avons isolé trois profils.
  • Limite : Eu égard à l'effectif, les résultats restent indicatifs.
