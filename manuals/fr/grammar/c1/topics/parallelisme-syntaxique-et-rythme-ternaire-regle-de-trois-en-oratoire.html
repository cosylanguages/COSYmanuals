Grammaire Française C1

Le rythme ternaire

Grouper par trois pour être retenu.

🎯 Objectif de communication : Vous savez construire un rythme ternaire et un parallélisme.
Exemples en contexte
  • Exemple 1 : Nous avons mesuré le coût, pesé le risque, consulté les équipes. — Trois verbes parallèles.
  • Exemple 2 : Un texte clair, un calendrier tenable, une équipe formée. — Trois groupes nominaux.
  • Exemple 3 : Ce n'est ni un retard, ni un échec, ni un abandon. — Négation ternaire.

👀 Qu'observez-vous ?

Ternaire : trois éléments de même nature et de longueur proche (verbe + objet, nom + adjectif), séparés par des virgules, souvent avec le troisième plus long. Parallélisme : même construction dans chaque branche.

Élément / Structure Rôle en français Exemple d'application
trois verbes + objets parallélisme verbal mesuré le coût, pesé le risque, consulté les équipes
trois groupes nominaux parallélisme nominal un texte clair, un calendrier tenable, une équipe formée
négation ternaire accumulation négative ni un retard, ni un échec, ni un abandon
troisième élément plus long chute … et une équipe enfin formée
virgules, pas de et avant le dernier rythme le coût, le risque, les équipes
quatre éléments rupture à éviter : le rythme se casse

Formule / Règle : Le ternaire fonctionne parce que l'oreille retient trois éléments : c'est la plus petite série qui donne une impression de complétude. Un groupe de quatre casse le rythme et un groupe de deux paraît incomplet dans un discours.

★ Pourquoi c'est important

Le parallélisme est la condition du ternaire : les trois éléments doivent être de même nature grammaticale. « Nous avons mesuré le coût, le risque a été pesé, et consulter les équipes » détruit l'effet.

💭 Pensez comme un francophone

L'absence de et avant le dernier élément est une convention du rythme ternaire oratoire ; dans un texte courant, et redevient naturel.

🗣️ Note de prononciation

ternaire /tɛʁ.nɛʁ/, le parallélisme /lə pa.ʁa.le.lism/.

Banque d'exemples complémentaires
  • Verbal : Nous avons écouté les usagers, vérifié les chiffres, corrigé le calendrier.
  • Nominal : Une décision claire, un calendrier réaliste, un suivi régulier.
  • Négatif : Ce n'est pas un refus, ni un report, ni une critique.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : nous avons mesuré le coût, le risque a été pesé, et consulter les équipes (parallélisme rompu)

✅ Correct : nous avons mesuré le coût, pesé le risque, consulté les équipes

❌ Erreur : un texte clair, un calendrier tenable, une équipe qui a été formée (longueurs trop inégales)

✅ Correct : un texte clair, un calendrier tenable, une équipe formée
