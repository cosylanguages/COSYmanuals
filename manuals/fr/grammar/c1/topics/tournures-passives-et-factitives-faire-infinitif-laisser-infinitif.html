Grammaire Française C1

Faire et laisser + infinitif

Attribuer une action à un agent secondaire.

🎯 Objectif de communication : Vous savez employer les constructions factitives.
Exemples en contexte
  • Exemple 1 : La direction a fait réviser la procédure par un cabinet externe. — Factitif avec agent.
  • Exemple 2 : Elle s'est laissé convaincre par les chiffres. — Laisser + infinitif.
  • Exemple 3 : On a fait valider le texte avant publication. — Factitif sans agent exprimé.

👀 Qu'observez-vous ?

Factitif : faire + infinitif + par + agent, laisser + infinitif + à / par, se faire + infinitif, se laisser + infinitif. Attention : l'accord du participe passé avec faire + infinitif est invariable.

Élément / Structure Rôle en français Exemple d'application
faire + infinitif + par factitif avec agent a fait réviser la procédure par un cabinet
faire + infinitif sans agent factitif implicite on a fait valider le texte
se faire + infinitif action subie il s'est fait surprendre par le délai
laisser + infinitif non-intervention elle a laissé passer l'occasion
se laisser + infinitif consentement elle s'est laissé convaincre
participe de faire invariable règle elle a fait réviser, non faite réviser

Formule / Règle : Faire + infinitif attribue l'action à un autre agent : la direction ne révise pas, elle fait réviser. C'est la construction qui permet de désigner le responsable sans décrire l'exécution.

★ Pourquoi c'est important

Le participe passé de faire reste invariable devant un infinitif : « elle a fait réviser », non « faite réviser ». C'est l'une des rares règles sans exception de l'accord du participe.

💭 Pensez comme un francophone

Laisser + infinitif marque l'absence d'intervention, se laisser l'acceptation : « elle s'est laissé convaincre » signifie qu'elle a cédé, non qu'on l'a trompée.

🗣️ Note de prononciation

faire réviser /fɛʁ ʁe.vi.ze/, se laisser /sə lɛ.se/.

Banque d'exemples complémentaires
  • Agent : Le comité a fait auditer les comptes par un tiers.
  • Subi : Le service s'est fait dépasser par les délais.
  • Consentement : Il s'est laissé porter par la discussion.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : elle a faite réviser la procédure
