Grammaire Française C1

Auquel, duquel, pour lesquelles

Employer les relatifs à préposition composée.

🎯 Objectif de communication : Vous savez choisir entre auquel, duquel et pour lesquelles.
Exemples en contexte
  • Exemple 1 : Le dossier auquel je me réfère date de mars. — Auquel = à + lequel.
  • Exemple 2 : L'accord duquel dépend le calendrier a été signé. — Duquel = de + lequel.
  • Exemple 3 : Les questions pour lesquelles nous sommes consultés sont techniques. — Préposition + lesquelles.

👀 Qu'observez-vous ?

Relatifs : auquel / auxquels / auxquelles (à + lequel), duquel / desquels / desquelles (de + lequel), pour lequel, sur laquelle, chez qui, avec qui. Personne : qui ; chose : lequel.

Élément / Structure Rôle en français Exemple d'application
auquel / auxquels à + lequel, chose le dossier auquel je me réfère
duquel / desquels de + lequel, chose l'accord duquel dépend le calendrier
pour lequel / lesquelles préposition libre les questions pour lesquelles nous sommes consultés
qui (personne) personne la personne à qui j'ai écrit
chez qui / avec qui personne, préposition le service chez qui nous avons déposé
lequel après préposition chose ou personne le point sur lequel nous butons

Formule / Règle : Le choix dépend de deux facteurs : la nature de l'antécédent (chose ou personne) et la préposition du verbe. Pour une personne, on emploie qui après préposition ; pour une chose, lequel et ses composés.

★ Pourquoi c'est important

Auquel et duquel sont des contractions obligatoires : « à lequel » et « de lequel » n'existent pas. L'erreur inverse, employer dont quand le verbe demande autre chose que de, est plus fréquente que l'oubli de la contraction.

💭 Pensez comme un francophone

Pour lequel, sur laquelle, dans lesquels s'emploient quand la préposition n'est pas à ou de : ils ne se contractent pas.

🗣️ Note de prononciation

auquel /o.kɛl/, duquel /dy.kɛl/.

Banque d'exemples complémentaires
  • Chose : Le rapport auquel nous nous référons est confidentiel.
  • De : Le comité duquel dépend la décision se réunit jeudi.
  • Personne : Le collègue avec qui j'ai travaillé est parti.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le rapport dont nous nous référons

✅ Correct : le rapport auquel nous nous référons

❌ Erreur : la personne auquel j'ai écrit

✅ Correct : la personne à qui j'ai écrit
