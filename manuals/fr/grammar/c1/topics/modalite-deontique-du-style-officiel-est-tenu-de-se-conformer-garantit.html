Grammaire Française C1

La modalité déontique officielle

Dire l'obligation dans un texte réglementaire.

🎯 Objectif de communication : Vous savez employer les tournures déontiques du style officiel.
Exemples en contexte
  • Exemple 1 : Le titulaire est tenu de se conformer aux prescriptions. — Obligation.
  • Exemple 2 : Le respect du délai garantit la recevabilité de la demande. — Condition de validité.
  • Exemple 3 : Nul ne peut être dispensé de cette formalité. — Obligation générale.

👀 Qu'observez-vous ?

Déontique : être tenu de + infinitif, devoir, être dans l'obligation de, se conformer à, garantir (comme condition), nul ne peut, il est fait obligation de, sous peine de.

Formule / Règle : La modalité déontique dit ce qui est obligatoire, permis ou interdit dans un cadre donné. Sa marque est l'impersonnalité : être tenu de, nul ne peut, il est fait obligation de placent l'obligation dans le texte, non dans la volonté de celui qui l'écrit.

★ Pourquoi c'est important

Garantir est ici un verbe de conditionnalité : « le respect du délai garantit la recevabilité » signifie que le délai est une condition, non que le délai suffise toujours.

💭 Pensez comme un francophone

Sous peine de attache la sanction au manquement : c'est ce qui distingue une obligation réglementaire d'une recommandation.

🗣️ Note de prononciation

être tenu de /ɛtʁ tə.ny də/, sous peine de /su pɛn də/.

Banque d'exemples complémentaires
  • Obligation : L'exploitant est tenu de déclarer tout incident sous 48 heures.
  • Condition : La production de l'attestation garantit l'instruction du dossier.
  • Sanction : La déclaration doit être faite sous peine d'irrecevabilité.
⚠️ Erreurs fréquentes à éviter

❌ Erreur : le titulaire doit de se conformer

✅ Correct : le titulaire est tenu de se conformer

❌ Erreur : sous peine de que

✅ Correct : sous peine de + nom
