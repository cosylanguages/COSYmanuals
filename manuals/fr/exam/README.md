# French exam manuals — DELF & DALF

Reference pages for the themes supplied for DELF B1, DELF B2, DALF C1 and DALF C2.
Each level page lists the official oral and written task shapes, the theme categories,
and links to the matching communication and grammar manuals.

The canonical catalogue lives in COSYpractice:
`data/exam/fr/delf-dalf-themes.json` (55 categories, 545 themes).

The curriculum pointers in `curriculums/fr/exam/` resolve to COSYplatform, which owns
the 25-lesson exam track for each level. Regenerate these pages if the catalogue changes.
