# French exam manuals — DELF & DALF

Reference pages for the themes supplied for DELF B1, DELF B2, DALF C1 and DALF C2.
Each level page lists the official oral and written task shapes, the theme categories,
the exam-format notes, the method advice and example subjects, and links to the
matching communication and grammar manuals.

The canonical catalogue lives in COSYpractice:
`data/exam/fr/delf-dalf-themes.json` (55 categories, 545 themes, plus format notes,
method and example subjects).

The curriculum pointers in `curriculums/fr/exam/` resolve to COSYplatform, which owns
the 25-lesson exam track for each level. Regenerate these pages if the catalogue changes.

Deduplication: the broad themes on the Français avec Pierre pages (work, education,
environment, consumption, media, society, tourism, technology, health) were already
covered by the catalogue categories, so they were not added again. The pages supplied
only the format details, method advice and example subjects that were missing.
