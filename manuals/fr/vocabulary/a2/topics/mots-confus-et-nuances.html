Mots confus et nuances essentielles (A2)

Guide de référence sur les paires de mots facilement confondus et les nuances de vocabulaire en français (A2).

🎯 Objectif lexical : Distinguer précisément les nuances de sens, choisir le terme exact selon le contexte et éviter les confusions fréquentes au niveau A2.

Mouvement & Position

  • partir vs quitter
    partir = s'en aller (sans COD) / quitter = s'éloigner de quelqu'un/quelque chose (avec COD)
  • arriver vs venir
    arriver = atteindre sa destination / venir = se déplacer vers le locuteur
  • entrer vs rentrer
    entrer = pénétrer dans un lieu / rentrer = retourner chez soi ou revenir
  • sortir vs partir
    sortir = quitter un espace fermé / partir = s'en aller pour un voyage ou une durée
  • monter vs augmenter
    monter = s'élever physiquement / augmenter = devenir plus grand en quantité/prix
  • descendre vs baisser
    descendre = aller vers le bas / baisser = diminuer un niveau/prix

Actions quotidiennes

  • acheter vs payer
    acheter = acquérir un bien / payer = régler la somme d'argent
  • gagner vs recevoir
    gagner = remporter ou mériter par le travail / recevoir = obtenir de quelqu'un
  • dépenser vs coûter
    dépenser = utiliser de l'argent / coûter = avoir un prix
  • prêter vs emprunter
    prêter = donner temporairement / emprunter = recevoir temporairement
  • louer vs acheter
    louer = payer pour l'usage temporaire / acheter = devenir propriétaire

Nourriture & Objets

  • plat vs assiette
    plat = mets préparé ou grand récipient / assiette = récipient individuel
  • nourriture vs aliment
    nourriture = alimentation en général / aliment = ingrédient/produit spécifique
  • recette vs réception
    recette = instructions de cuisine ou revenus / réception = accueil ou fête
  • goût vs odeur
    goût = saveur en bouche / odeur = sensation olfactive

Émotions

  • aimer vs adorer
    aimer = éprouver de l'affection/goût / adorer = aimer passionnément
  • peur vs crainte
    peur = émotion vive devant le danger / crainte = appréhension plus intellectuelle
  • sentir vs ressentir
    sentir = percevoir par les sens / ressentir = éprouver une émotion profonde
  • être heureux vs être content
    heureux = état de bonheur profond / content = satisfait d'une situation précise

Vérification des connaissances

1. Choisissez le mot approprié selon la nuance recherchée.
